**TaskInspectionDao (`mobile/lib/features/projects/data/task_inspection_dao.dart`):**

Follow `TaskNoteDao` pattern exactly:
```dart
@DriftAccessor(tables: [TaskInspections, SyncQueue])
class TaskInspectionDao extends DatabaseAccessor<AppDatabase> with _$TaskInspectionDaoMixin {
  TaskInspectionDao(super.db);

  // Watch all inspections for a task (audit trail)
  Stream<List<TaskInspection>> watchByTaskId(String taskId) {
    return (select(taskInspections)
      ..where((t) => t.taskId.equals(taskId) & t.deletedAt.isNull())
      ..orderBy([(t) => OrderingTerm.desc(t.createdAt)]))
    .watch();
  }

  // Create inspection + sync queue entry in a transaction
  Future<void> createInspection(TaskInspectionsCompanion inspection) {
    return transaction(() async {
      await into(taskInspections).insert(inspection);
      await into(syncQueue).insert(SyncQueueCompanion.insert(
        id: Value(const Uuid().v4()),
        entityType: 'task_inspection',
        entityId: inspection.id.value,
        operation: 'CREATE',
        payload: jsonEncode({
          'taskId': inspection.taskId.value,
          'decision': inspection.decision.value,
          'checklistResults': inspection.checklistResults.value,
          'rejectionReason': inspection.rejectionReason.value,
          'rejectionComment': inspection.rejectionComment.value,
        }),
        status: const Value('pending'),
        attemptCount: const Value(0),
        createdAt: DateTime.now(),
      ));
    });
  }

  // Upsert from server sync
  Future<void> upsertFromServer(TaskInspectionsCompanion data) {
    return into(taskInspections).insertOnConflictUpdate(data);
  }
}
```

**SiteWalkFlagDao (`mobile/lib/features/projects/data/site_walk_flag_dao.dart`):**

Same pattern, plus a `convertFlag` method that wraps both the flag status update and punch item creation in a single Drift transaction:
- `watchByProjectId(String projectId)` -- stream of flags for a project, ordered by createdAt desc
- `createFlag(SiteWalkFlagsCompanion flag)` -- dual-write with sync queue (entityType: 'site_walk_flag')
- `updateStatus(String flagId, String status)` -- update flag status + sync queue UPDATE entry
- `convertFlag(String flagId, PunchListItemsCompanion punchItem)` -- **wraps BOTH writes in a single Drift transaction**: (1) update flag status to 'converted' + sync queue UPDATE entry, (2) insert punch list item + sync queue CREATE entry. This ensures atomicity -- if either write fails, neither persists. The caller (UI layer) constructs the PunchListItemsCompanion with `sourceFlagId: Value(flagId)` and all copied fields (description, photoUrl, annotationData).
- `upsertFromServer(SiteWalkFlagsCompanion data)` -- for server sync

```dart
Future<void> convertFlag(String flagId, PunchListItemsCompanion punchItem) {
  return transaction(() async {
    // 1. Update flag status to 'converted'
    await (update(siteWalkFlags)..where((f) => f.id.equals(flagId)))
        .write(SiteWalkFlagsCompanion(
          status: const Value('converted'),
          updatedAt: Value(DateTime.now()),
        ));
    await into(syncQueue).insert(SyncQueueCompanion.insert(
      id: Value(const Uuid().v4()),
      entityType: 'site_walk_flag',
      entityId: flagId,
      operation: 'UPDATE',
      payload: jsonEncode({'status': 'converted'}),
      status: const Value('pending'),
      attemptCount: const Value(0),
      createdAt: DateTime.now(),
    ));
    // 2. Insert punch list item
    await into(punchListItems).insert(punchItem);
    await into(syncQueue).insert(SyncQueueCompanion.insert(
      id: Value(const Uuid().v4()),
      entityType: 'punch_list_item',
      entityId: punchItem.id.value,
      operation: 'CREATE',
      payload: jsonEncode({
        'tradeScopeId': punchItem.tradeScopeId.value,
        'description': punchItem.description.value,
        'sourceFlagId': flagId,
      }),
      status: const Value('pending'),
      attemptCount: const Value(0),
      createdAt: DateTime.now(),
    ));
  });
}
```
