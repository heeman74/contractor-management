6. `test_contractor_cannot_inspect` -- Use contractor_token. POST /tasks/{id}/inspect. Assert 403 (only GC/admin can inspect).
7. `test_reject_task_reblocks_dependents` -- Create task A (complete) with a FS (finish-to-start) dependency to task B. Verify task B is not blocked (since A is complete).
