## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, sort icon margin |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Card content padding, form field gaps |
| lg | 24px | Card-to-card gaps in sidebar column (`space-y-4` = 16px; `space-y-6` = 24px) |
| xl | 32px | Section-level padding |
| 2xl | 48px | Empty state vertical padding (`py-12`) |
| 3xl | 64px | Page-level spacing (unused in existing pages — use `space-y-6` max) |

Exceptions:
- Tab bar underline offset: `-mb-px` (1px) — preserved from Phase 14 pattern
- Table cell: `py-3 px-4` (12px/16px) — matches existing DataTable
- Status badge: `px-2.5 py-0.5` (10px/2px) for md; `px-2 py-0.5` for sm
- Touch targets: 44px minimum for interactive row areas (cursor-pointer rows)
- Two-column main/sidebar gap: `gap-8` (32px) — matches Phase 14 job detail exactly

## Interaction Contracts

### Quote Builder — Inline Editing
- Tab key navigates: Description → Qty → Unit → Unit Price → next row Description
- Enter key in last cell of last row: appends a new empty row and focuses its Description cell
- Financial summary updates on every `onChange` event (via `watch()` — no debounce)
- "Load from template" Select: on change, confirm with user if rows exist ("Replace current line items?"), then populate
- Drag handle: `cursor-grab`, `cursor-grabbing` during drag. Visual: dragged row has `opacity-50 bg-blue-50`
- Delete row (×): immediate removal, no confirmation (row is in-form state, not yet saved)

### Quote Detail — Send Action
- "Send Quote" button → Dialog opens → Admin confirms → `POST /quotes/{id}/send` → optimistic status update → toast "Quote sent to {client_name}"
- Button shows loading spinner during mutation (`disabled` + spinner icon)

### Invoice Detail — Record Payment
- "Record Payment" button → inline form expands below payment summary (not a dialog)
- Amount field: validates `0 < amount <= balance`, shows inline error "Amount cannot exceed remaining balance"
- "Save Payment" → `PATCH /invoices/{id}/payment_status` with `{ amount_paid: current + input }` → TanStack Query invalidates invoice → Paid/Balance display updates

### PDF Download
- "Download PDF" button → loading state (spinner, disabled) → raw `fetch` via proxy → `resp.blob()` → object URL → `<a download>` trigger → URL revoked
- On error: toast.error "PDF download failed. Try again.", { duration: Infinity }

### Error Handling
- All `toast.error()` calls: `{ duration: Infinity }` — matches Phase 13 decision
- API load failure: show error card (`rounded-xl bg-white p-8 text-center ring-1 ring-foreground/10`) with retry message
- Mutation failure: toast only — no page-level error state
