Backend prep: extend FastAPI to support web cookie-based auth alongside existing mobile Bearer auth.

This plan makes `get_current_user` dual-source (Bearer + Cookie), adds CORS for the web origin, adds the `client_type` DB column, and creates backend integration tests.
