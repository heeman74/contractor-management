    1. **__init__.py**: Empty file.

    2. **models.py**: Four SQLAlchemy models inheriting from TenantScopedModel:

    ```python
    class ChatThread(TenantScopedModel):
        __tablename__ = "chat_threads"
        project_id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), ForeignKey("projects.id"))
        thread_type: Mapped[str]  # 'scope' or 'project_wide'
        trade_scope_id: Mapped[uuid.UUID | None] = mapped_column(UUID(as_uuid=True), ForeignKey("trade_scopes.id"), nullable=True)
        name: Mapped[str]
        # relationships
        memberships = relationship("ChatMembership", back_populates="thread", lazy="raise")
        messages = relationship("ChatMessage", back_populates="thread", lazy="raise")

    class ChatMessage(TenantScopedModel):
        __tablename__ = "chat_messages"
        thread_id, sender_id, content (nullable), seq (BigInteger),
        attachment_url (nullable), attachment_type (nullable),
        annotation_data (nullable), mentions (JSONB default []),
        mention_all (Boolean default False)
        # relationships
        thread = relationship("ChatThread", back_populates="messages", lazy="raise")

    class ChatMembership(TenantScopedModel):
        __tablename__ = "chat_memberships"
        thread_id, user_id, muted (Boolean default False), joined_at
        # relationships
        thread = relationship("ChatThread", back_populates="memberships", lazy="raise")

    class ChatReadReceipt(TenantScopedModel):
        __tablename__ = "chat_read_receipts"
        thread_id, user_id, last_read_seq (BigInteger), read_at
    ```

    NOTE: ChatMessage does NOT have updated_at (messages are immutable — no edits). Override TimestampMixin to exclude updated_at, or add updated_at but never use it. Prefer keeping updated_at from the mixin for consistency — it won't hurt.

    All relationships use `lazy="raise"` per CLAUDE.md.

    3. **repository.py**: Two repositories:
    - `ChatThreadRepository(TenantScopedRepository[ChatThread])` with:
      - `list_by_project(project_id)` — selectinload memberships, order by updated_at desc
      - `get_with_memberships(thread_id)` — selectinload memberships
      - `find_scope_thread(project_id, trade_scope_id)` — find existing scope thread
    - `ChatMessageRepository(TenantScopedRepository[ChatMessage])` with:
      - `list_by_thread(thread_id, before_seq=None, limit=50)` — cursor pagination by seq desc, return ordered asc
      - `get_by_uuid(message_id)` — for dedup check

    4. **service.py**: `ChatService(TenantScopedService[ChatThread])` with:
    - `repository_class = ChatThreadRepository`
    - `__init__(self, db)`: Also create `self.message_repo = ChatMessageRepository(db)`
    - `create_scope_thread(project_id, trade_scope_id, trade_name, contractor_id, gc_user_id)` — create thread + 2 memberships (GC + contractor). Check if thread already exists first (idempotent).
    - `create_project_wide_thread(project_id, project_name, member_user_ids)` — create thread + N memberships.
    - `ensure_membership(thread_id, user_id)` — add if not exists (for auto-join when new contractor assigned).
    - `send_message(thread_id, sender_id, content, message_id, attachment_url=None, attachment_type=None, annotation_data=None, mentions=None, mention_all=False)` — insert with ON CONFLICT DO NOTHING on id (dedup by client UUID). Seq assigned by DB default from chat_message_seq.
    - `get_messages(thread_id, before_seq=None, limit=50)` — delegate to message_repo.list_by_thread.
    - `list_threads_for_user(project_id, user_id)` — threads where user has membership, with last message and unread count.
    - `mark_read(thread_id, user_id, seq)` — upsert chat_read_receipts using `insert().on_conflict_do_update()` with `where last_read_seq < seq`.
    - `get_read_receipts(thread_id)` — list read receipts for thread.
    - `toggle_mute(thread_id, user_id, muted: bool)` — update membership muted flag.

    Do NOT call db.commit() — get_db handles it (per CLAUDE.md). Use db.flush() when you need generated seq values.

    5. **schemas.py**: Pydantic schemas inheriting BaseResponseSchema:
    - `ChatThreadResponse`: id, project_id, thread_type, trade_scope_id, name, created_at, last_message (optional nested), unread_count (int), member_count (int)
    - `ChatMessageResponse`: id, thread_id, sender_id, sender_name (str), content, seq, attachment_url, attachment_type, annotation_data, mentions, mention_all, created_at
    - `ChatReadReceiptResponse`: user_id, user_name (str), last_read_seq, read_at
    - `SendMessageRequest`: id (UUID, client-generated), content (Optional[str]), attachment_url (Optional), attachment_type (Optional), annotation_data (Optional), mentions (list[UUID] default []), mention_all (bool default False)
    - `MarkReadRequest`: seq (int)

    6. **ws_manager.py**: `ConnectionManager` class:
    - `_connections: dict[str, dict[str, WebSocket]]` — thread_id -> user_id -> WebSocket
    - `_redis: redis.asyncio.Redis | None`
    - `_relay_tasks: dict[str, asyncio.Task]` — track relay tasks per thread for cleanup
    - `get_redis()` — lazy init from settings.redis_url
    - `connect(websocket, thread_id, user_id)` — accept, register, start relay if first connection for thread
    - `disconnect(websocket, thread_id, user_id)` — remove, cancel relay if last connection for thread
    - `broadcast_to_thread(thread_id, payload)` — publish to `chat:thread:{thread_id}` Redis channel
    - `relay_from_redis(thread_id)` — subscribe to Redis channel, relay to local connections. Catch individual send errors (don't let dead connection block others).
    - Module-level singleton: `manager = ConnectionManager()`
