<objective>
Land the financial data schema: five new tenant-scoped tables with RLS, seed the four
protected system cost categories per company, and backfill existing companies'
project_manager rows with the finance keys. No CRUD endpoints ship this phase — models,
Pydantic create-schemas (with XOR validators), and the migration only.

Purpose: FINSEC-01 foundation — the schema every later financial phase builds on, plus
the existing-company backfill so PMs at pre-migration companies actually receive the
finance defaults added in plan 01.
Output: app/features/finance/{__init__,models,schemas}.py, migration 0032, and XOR
validator unit tests.

RESOLVED OPEN QUESTIONS (from 30-RESEARCH.md):
- Q1: Ship CostCategory model + migration + seed ONLY. No CostCategoryRepository/Service/
  router this phase — Phase 31 builds the thin CRUD layer (mirroring TradeCatalogService
  + an is_system delete-guard) alongside the cost-entry form that consumes it.
- Q2: The Alembic DB role `appuser` is NOSUPERUSER NOBYPASSRLS (confirmed in
  docker/init.sql) and company_role_permissions has FORCE ROW LEVEL SECURITY since 0027.
  Therefore a bare cross-tenant UPDATE is filtered out. The PM backfill MUST loop
  per-company with `SET LOCAL app.current_company_id = '<uuid>'` before each UPDATE
  (the fallback the research flagged). The cost_categories seed avoids this by running
  as a plain INSERT BEFORE `ENABLE ROW LEVEL SECURITY` on the fresh table, exactly as
  0027's backfill did.
</objective>

       company_role_permissions already has FORCE RLS (since 0027) and appuser is
       NOBYPASSRLS, a bare UPDATE is filtered out — loop per company with tenant context:
       ```python
       conn = op.get_bind()
       company_ids = conn.execute(sa.text("SELECT id FROM companies")).scalars().all()
       for cid in company_ids:
           conn.execute(sa.text(f"SET LOCAL app.current_company_id = '{cid}'"))
           conn.execute(sa.text(
               "UPDATE company_role_permissions "
               "SET permissions = permissions || "
               "'[\"finance.view\",\"finance.manage\",\"finance.rates.manage\"]'::jsonb, "
               "updated_at = now() "
               "WHERE role = 'project_manager' "
               "AND NOT (permissions @> '[\"finance.view\"]'::jsonb)"
           ))
       ```
