**URL state management:**
- Use `useSearchParams()` and `useRouter()` from `next/navigation`
- Read: `tab` (default "all"), `page` (default "1"), `q` (default ""), `sort` (default "created_at"), `dir` (default "desc")
- Tab change: set `tab={status}`, reset `page=1`
- Search: debounce 300ms with `useEffect` + `useRef` + `setTimeout`, update `q` param, reset `page=1`
- Sort: click header toggles asc/desc, updates `sort` and `dir` params
- Page change: increment/decrement `page` param

**Data fetching with TanStack Query:**
- Main list query:
  ```typescript
  const PAGE_SIZE = 25;
  const { data: jobs, isLoading } = useQuery({
    queryKey: ["jobs", { tab: activeTab, page, search: debouncedSearch, sort: sortCol, dir: sortDir }],
    queryFn: () => {
      if (debouncedSearch) {
        // Use search endpoint when query is non-empty
        const params = new URLSearchParams();
        params.set("q", debouncedSearch);
        if (activeTab !== "all" && activeTab !== "requests") params.set("status", activeTab);
        return apiGet<Job[]>(`/api/v1/jobs/search?${params}`);
      }
      // Use list endpoint
      const params = new URLSearchParams();
      if (activeTab !== "all" && activeTab !== "requests") params.set("status", activeTab);
      params.set("offset", String((page - 1) * PAGE_SIZE));
      params.set("limit", String(PAGE_SIZE));
      return apiGet<Job[]>(`/api/v1/jobs?${params}`);
    },
    enabled: activeTab !== "requests",
  });
  ```
- Requests query (only when tab is "requests"):
  ```typescript
  const { data: requests, isLoading: requestsLoading } = useQuery({
    queryKey: ["job-requests", { page }],
    queryFn: () => apiGet<JobRequestResponse[]>("/api/v1/jobs/requests"),
    enabled: activeTab === "requests",
  });
  ```
- Tab count queries (parallel, always enabled):
  ```typescript
  const statuses: JobStatus[] = ["quote", "scheduled", "in_progress", "complete", "invoiced"];
  // Use individual useQuery for each status count
  const countQueries = statuses.map(s => useQuery({
    queryKey: ["jobs", "count", s],
    queryFn: () => apiGet<Job[]>(`/api/v1/jobs?status=${s}&limit=200`),
    select: (data) => data.length,

  ```

  const requestsCount = useQuery({
