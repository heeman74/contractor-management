## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, sort arrow gap from column label |
| sm | 8px | Table cell internal padding, badge-to-text gap |
| md | 16px | Default section padding (px-4), card content padding |
| lg | 24px | Section separation within job detail main content |
| xl | 32px | Gap between main content column and sidebar column |
| 2xl | 48px | Page-level top padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Status tab bar: `py-3 px-4` (12px vertical, 16px horizontal) to match Stripe-style compact tab height
- Table rows: `py-3 px-4` (12px vertical) for compact density
- Sidebar action button area: `p-4` with `gap-2` (8px) between status badge and action button
- Touch targets (sort headers, tab buttons): minimum 44px height per accessibility standard
- Two-column layout split: `grid-cols-[1fr_360px]` giving ~65% main / ~35% sidebar at 1280px viewport

Note: 12px (`py-3`) is outside the standard spacing scale and is permitted **only** in the two explicitly declared contexts above (tab bar and table rows). Do not use `py-3` elsewhere to prevent spacing drift.

## Typography

Two weights only — no intermediate weight permitted in this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (font-normal) | 1.5 |
| Label | 12px (text-xs) | 600 (font-semibold) | 1.4 |
| Heading | 20px (text-xl) | 600 (font-semibold) | 1.2 |
| Display | 28px (text-2xl) | 600 (font-semibold) | 1.2 |

Source: Established in Phase 13 codebase — `page.tsx` uses `text-xl font-semibold` for page headings, `text-sm` for body, `text-xs` for metadata. Display size reserved for count numbers in tab badges if rendered large (not used in Phase 14 at 28px — tab count badges use `text-xs`).

Notes specific to this phase:
- Column headers in DataTable: `text-xs font-semibold text-gray-500 uppercase tracking-wide` (consistent with existing activity table pattern; weight raised from medium to semibold to comply with 2-weight rule)
- Job description in detail page main column: `text-sm` body weight 400, `leading-relaxed` (1.625)
- Section headings within detail page (Notes, Activity, Time Tracking): `text-sm font-semibold text-gray-900`
- Sidebar metadata labels (Status, Contractor, Client, Address): `text-xs font-semibold text-gray-500 uppercase tracking-wide`
- Sidebar metadata values: `text-sm font-normal text-gray-900`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background`: oklch(1 0 0) → white | Page background, table row background, main content area |
| Secondary (30%) | `--sidebar`: oklch(0.985 0 0) → near-white; sidebar nav: `bg-gray-900` | Sidebar nav, card surfaces (`bg-white ring-1 ring-foreground/10`), tab bar background |
| Accent (10%) | `--primary`: oklch(0.205 0 0) → near-black; indigo-600 for active states | Active sidebar nav item, primary action button (shadcn Button default), active tab indicator |
| Destructive | `--destructive`: oklch(0.577 0.245 27.325) → red | Cancel Job action in dropdown, Cancel confirmation dialog destructive button |

Accent reserved for:
- Active tab underline indicator
- Active sidebar nav item background (`bg-indigo-600`)
- Primary CTA button ("Mark In Progress", "Approve Request") — shadcn Button `variant="default"`
- Sort arrow indicators on active sort column (`text-gray-900` vs inactive `text-gray-400`)
- Breadcrumb current page label

Destructive reserved for:
- "Cancel Job" option in transition DropdownMenu (red text)
- Cancel Job confirmation dialog's destructive button
- Inline transition error banner (`bg-red-50 border border-red-200 text-red-700`)

## Interaction Contracts

### Tab switching
- Tab click → update URL search param `?tab={status}` + reset `?page=1`
- TanStack Query re-fetches on queryKey change — no manual refetch call
- Active tab: bottom border `border-b-2 border-gray-900`, text `text-gray-900 font-semibold`
- Inactive tab: `text-gray-500 hover:text-gray-700`
- "Requests" tab separated by a vertical `|` divider from status tabs

### Search bar
- Debounce: 300ms (useEffect + useRef with setTimeout)
- Typing updates URL `?q={value}` after debounce, resets to page 1
- Clearing search removes `?q` param entirely
- Search and active status tab are combinable filters

### Column sort
- Click column header: toggle asc/desc, update URL `?sort={column}&dir={asc|desc}`
- Active sort column header: show `ArrowUp` or `ArrowDown` icon (lucide-react), `text-gray-900`
- Inactive sort columns: show `ArrowUpDown` icon (lucide), `text-gray-400`
- Default sort: Date column, descending (newest first)

### Status transition button + dropdown
- Primary Button (`variant="default"`): shows next logical status — e.g. "Mark In Progress"
- Right side of button: `DropdownMenuTrigger` with `ChevronDown` icon
- Dropdown items:
  - Forward transitions: `DropdownMenuItem` (normal)
  - Revert transition: `DropdownMenuItem` with `text-gray-500` (secondary visual weight)
  - Cancel Job: `DropdownMenuItem` with `text-destructive` (red)
- Forward transitions: execute on click, no dialog
- Revert + Cancel: open `Dialog` for confirmation before executing
- After success: `queryClient.setQueryData(["job", id], updatedJob)` — no refetch round-trip
- Transition error: render `Alert variant="destructive"` banner below action button, clear on next action attempt

### Photo note lightbox
- Thumbnail grid: `grid-cols-4 gap-2`, each thumbnail `aspect-square rounded overflow-hidden bg-gray-100`
- Click thumbnail: open shadcn `Dialog` with `max-w-3xl`, single `<img>` full-width with `object-contain`
- Photo unavailable: show `bg-gray-100` placeholder with "Photo unavailable" text-xs centered
- Close: `X` button top-right of dialog, click outside, or Escape key (Dialog default behavior)

### Pagination
- Show: `← Previous` and `Next →` buttons as shadcn `Button variant="outline" size="sm"`
- "Has more" heuristic: if `data.length === PAGE_SIZE (25)`, show Next; if `data.length < PAGE_SIZE`, disable Next
- Page numbers: show current page and neighbors if available — simple `[1] [2] [3]` inline buttons
- Pagination row: `flex items-center justify-between` — item count left, controls right

### Request review flow
- Approve: no confirmation dialog (positive action) → `POST /jobs/requests/{id}/review {action:"accepted"}` → on success redirect to `/jobs/{converted_job_id}`
- Decline: open `Dialog` with required reason textarea → `POST` with `{action:"declined", decline_reason: value}` → on success navigate to `/jobs?tab=requests` + success toast
