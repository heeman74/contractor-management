    **QuoteService additions** (add to existing class):

    1. `async def create_for_scope(self, trade_scope_id: uuid.UUID, data: QuoteCreate, user_id: uuid.UUID) -> Quote`:
       - Validate trade_scope exists (db.get TradeScope, 404 if None)
       - Override data.trade_scope_id = trade_scope_id, data.job_id = None
       - Create Quote with trade_scope_id set, job_id=None
       - Use existing `_replace_line_items` for line items
       - Append status_history event "created"
       - db.flush() and return with selectinload(Quote.line_items)

    2. `async def list_by_scope(self, trade_scope_id: uuid.UUID) -> list[Quote]`:
       - SELECT from Quote WHERE trade_scope_id = trade_scope_id AND deleted_at IS NULL
       - Use .options(selectinload(Quote.line_items))
       - Order by created_at DESC

    3. `async def aggregate_by_project(self, project_id: uuid.UUID) -> dict`:
       - Query: SELECT trade_scopes.id, trade_scopes.trade_name, COUNT(quotes.id), SUM(quote_line_items.quantity * quote_line_items.unit_price) FROM trade_scopes LEFT JOIN quotes ON quotes.trade_scope_id = trade_scopes.id AND quotes.deleted_at IS NULL LEFT JOIN quote_line_items ON quote_line_items.quote_id = quotes.id AND quote_line_items.deleted_at IS NULL WHERE trade_scopes.project_id = project_id AND trade_scopes.deleted_at IS NULL GROUP BY trade_scopes.id, trade_scopes.trade_name
       - Return dict with per-scope breakdown and grand total

    **InvoiceService additions** (add to existing class):

    4. `async def generate_from_scope(self, trade_scope_id: uuid.UUID, user_id: uuid.UUID) -> Invoice`:
       - Validate trade_scope exists (404 if None)
       - Query ProjectTask WHERE scope_id = trade_scope_id AND status = 'complete' AND deleted_at IS NULL
       - Build InvoiceLineItemCreate list: each completed task becomes a line item with description=task.title, item_type='labor', quantity=task.estimated_hours or 1.0, unit='hr', unit_price=0.00 (GC fills in)
       - Look for approved quote on this scope to inherit tax_rate and discount settings; if none, use company defaults (tax_rate=0, no discount)
       - Generate invoice_number via existing `_generate_invoice_number`
       - Create Invoice with trade_scope_id=trade_scope_id, job_id=None, status='unpaid', issued_at=now()
       - Use `_replace_line_items` for line items
       - db.flush() and return with selectinload(Invoice.line_items)

    5. `async def generate_progress_invoice(self, trade_scope_id: uuid.UUID, milestone_id: uuid.UUID, user_id: uuid.UUID) -> Invoice`:
       - Get milestone from DB (404 if None)
       - Atomic double-billing check: `UPDATE billing_milestones SET is_invoiced=TRUE WHERE id=? AND is_invoiced=FALSE RETURNING id` — if 0 rows updated, raise HTTPException(409, "Milestone already invoiced")
       - Compute amount: get scope's approved quote total (SUM of line_items.quantity * unit_price from approved quote), multiply by milestone.percentage / 100
       - If no approved quote for scope, raise HTTPException(400, "No approved quote for this trade scope — cannot calculate progress invoice amount")
       - Generate invoice_number
       - Create Invoice with trade_scope_id, milestone_id, job_id=None, single line item: description=f"Progress billing: {milestone.name} ({milestone.percentage}%)", quantity=1, unit='ea', unit_price=computed_amount, item_type='labor'
       - Inherit tax_rate from the approved quote
       - db.flush() and return

    6. `async def aggregate_by_project(self, project_id: uuid.UUID) -> dict`:
       - Query: SELECT trade_scopes.id, trade_scopes.trade_name, COUNT(invoices.id), SUM(invoice totals), SUM(invoices.amount_paid) FROM trade_scopes LEFT JOIN invoices ON invoices.trade_scope_id = trade_scopes.id AND invoices.deleted_at IS NULL WHERE trade_scopes.project_id = project_id AND trade_scopes.deleted_at IS NULL GROUP BY trade_scopes.id, trade_scopes.trade_name
       - Return dict with per-scope totals and project grand total (total_billed, total_paid, total_outstanding)
