**1. Add heatmap schemas to `schemas.py`** (append after DashboardResponse class):

```python
class UtilizationWeekItem(BaseModel):
    """Single week of utilization data for one contractor."""
    iso_week: str          # "2026-W10"
    booked_hours: Decimal = Decimal("0")
    available_hours: Decimal = Decimal("0")
    utilization_percent: Decimal = Decimal("0")

class UtilizationHeatmapContractor(BaseModel):
    """One contractor's row in the heatmap grid."""
    contractor_id: str
    contractor_name: str
    weeks: list[UtilizationWeekItem]

class UtilizationHeatmapResponse(BaseModel):
    """Full heatmap grid: column headers + contractor rows."""
    weeks: list[str]  # ordered ISO week labels for column headers
    contractors: list[UtilizationHeatmapContractor]
```

**2. Add `get_utilization_heatmap` method to `ReportingService` in `service.py`:**

- Import the new schemas: `UtilizationWeekItem, UtilizationHeatmapContractor, UtilizationHeatmapResponse`
- Use ISO week expression: `func.to_char(func.date_trunc("week", func.lower(Booking.time_range)), 'IYYY-"W"IW').label("iso_week")`
- Duration hours expression: same pattern as existing `_get_contractor_utilization` — `func.extract("epoch", func.upper(Booking.time_range) - func.lower(Booking.time_range)) / cast(3600, Numeric)`
- Query: `select(User.id, contractor_name_expr, iso_week_expr, booked_hours_expr)` with `.join(UserRoleModel, ...).join(Booking, ..., isouter=True)` — same LEFT JOIN pattern as `_get_contractor_utilization`
- WHERE: `User.deleted_at.is_(None), UserRoleModel.deleted_at.is_(None)`, plus booking date conditions on `func.lower(Booking.time_range)`
- GROUP BY: `User.id, User.first_name, User.last_name, iso_week_expr`
- ORDER BY: `User.first_name, iso_week_expr`
- Post-process: Build a dict of `contractor_id -> {name, weeks_dict}`. Compute ordered list of all unique ISO week strings. For each contractor, fill in zero-booking weeks (weeks where contractor has no rows). Use fixed 40h available_hours per week. Compute `utilization_percent = min(100, booked / 40 * 100)`.
- Method signature: `async def get_utilization_heatmap(self, company_id: uuid.UUID, start_date: date | None, end_date: date | None) -> UtilizationHeatmapResponse`
