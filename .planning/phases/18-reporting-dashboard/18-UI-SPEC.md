## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, heatmap cell horizontal margin (`mx-1`) |
| sm | 8px | Inner card padding, button icon gap |
| md | 16px | Default element spacing, card content padding |
| lg | 24px | Section padding, chart card internal spacing |
| xl | 32px | Grid gap between chart cards |
| 2xl | 48px | Page-level top spacing |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Heatmap cells: fixed `h-8` (32px height) with `mx-1` (4px) horizontal margin — nearest valid spacing value to RESEARCH.md Pattern 4
- Chart container height: 280px minimum (not a spacing token — a content sizing constraint for `ResponsiveContainer`)
- Chart card container: `min-h-[300px]` to prevent ResponsiveContainer width-0 on initial render

Source: 8-point grid established by shadcn/ui base. Heatmap cell margin uses `mx-1` (4px) — the nearest multiple-of-4 value.

## Interaction Contract

### Date range filter

| Interaction | Behavior |
|-------------|----------|
| Click preset button (Last 7d, 30d, 90d, YTD) | Updates `dateRange` state, active button gets indigo accent background, TanStack Query refetches both queries |
| Click "Custom" | Opens Popover with 2-month Calendar in `mode="range"` |
| Select complete range in Calendar | Closes Popover automatically when both `from` and `to` are selected; triggers refetch |
| Page load | Default range = Last 30 days preset (pre-selected) |

### Chart click-to-drill-down

| Chart | Click target | Navigation |
|-------|-------------|------------|
| Jobs by Status BarChart | Bar element | `router.push('/jobs?status={status}')` |
| Revenue AreaChart | Area/bar segment by month | `router.push('/invoices?month={YYYY-MM}')` |
| Quote Conversion PieChart | Pie slice | `router.push('/quotes?status={status}')` |
| Utilization Heatmap | Cell | No navigation — tooltip only (cell click not required by CONTEXT.md) |

All clickable chart elements: `cursor="pointer"` on Recharts element.

### Tooltips

All 3 Recharts charts (AreaChart, BarChart, PieChart): custom `<Tooltip>` with:
- Container: `bg-white border border-border rounded-md shadow-sm p-2`
- Content: Label (14px normal) + Value (14px normal)
- Revenue: `$${value.toLocaleString('en-AU', { minimumFractionDigits: 2 })}` format
- Jobs count: integer
- Quote conversion: count + percentage of total (e.g., "12 (60%)")
- Heatmap cells: use `title` attribute tooltip only (`title="{contractor} — Week {W}: {pct}%"`)

### CSV download

Per chart: one "Download CSV" button with `Download` icon (lucide) at outline/sm size.
- Placement: top-right of ChartCard header, adjacent to icon container
- Behavior: client-side Blob download (Pattern 5 from RESEARCH.md), no loading state
- Filename pattern: `{chart-slug}-{startDate}-to-{endDate}.csv`
  - Example: `revenue-2026-02-18-to-2026-03-19.csv`

### Animations

Default Recharts animations are enabled (do not set `isAnimationActive={false}`):
- AreaChart: lines draw in from left
- BarChart: bars grow from baseline
- PieChart: slices expand from center

Source: CONTEXT.md "Subtle Recharts default animations."

## States Contract

For each chart card, implement these 4 states:

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | `isLoading === true` | Skeleton: `<Skeleton className="h-[300px] w-full rounded-md" />` inside ChartCard |
| Error | `isError === true` | Sonner `toast.error(...)` fires; chart area shows `<p className="text-sm text-muted-foreground text-center py-16">Failed to load data.</p>` |
| Empty | Data returned but all values are 0 / empty arrays | Chart area replaced with empty state: centered icon + heading + body text (see copywriting above) |
| Populated | Data returned with values | Normal chart render |

Heatmap-specific: if `contractors` array is empty for the range, show empty state identical to other charts.

## Accessibility Contract

- All chart cards must have `aria-label` on the card container: `aria-label="{Chart Title} chart"`
- Heatmap cells must have `title` attribute for tooltip (hover-accessible on desktop)
- Date preset buttons: `aria-pressed={isActive}` to communicate selected state
- CSV download button: `aria-label="Download {Chart Title} as CSV"`
- Recharts `ResponsiveContainer` wrapper: no additional ARIA required (SVG charts are decorative with KPI number as primary data source)
- Error and empty state paragraphs: `role="status"` for screen reader announcement
