<objective>
Add the typed web data layer for the three new financial endpoints: response
types, snake_case→camelCase mappers, and permission-gated TanStack Query hooks
under the existing `cost-entries` key prefix.

Purpose: the pages must receive already-parsed, correctly-typed props and must
not fetch before permissions are known. The `enabled: can("finance.view")` gate
is what makes the SC3 Playwright assertion ("zero `/api/v1/financials/*`
requests on a cold load") test something real rather than a Redux hydration
accident.
Output: extended `types.ts`, `api.ts`, `hooks.ts` + jest mapping tests.
</objective>

`GET /api/v1/financials/company`
```json
{
  "portfolio": {
    "cost": "121300.00",
    "quoted_revenue": "18400.00",
    "incomplete_project_count": 3,
    "margin": { "revenue": "182400.00", "revenue_basis": "mixed", "margin": "61100.00",
                "margin_percent": "33.5", "incomplete": true, "incomplete_reasons": ["unrated_labor"] }
  },
  "projects": [
    { "project_id": "…", "name": "Downtown Remodel", "status": "active", "cost": "40120.00",
      "margin": { …MarginSummary… },
      "budget": { "budget_id": "…", "total": "10000.00", "spent": "11200.00",
                  "remaining": "-1200.00", "percent_used": "112.0" } }
  ],
  "attention": [
    { "project_id": "…", "project_name": "Downtown Remodel", "project_status": "active",
      "tier": "overrun", "anchor_label": "Downtown Remodel — Plumbing scope",
      "spent": "11200.00", "budget_total": "10000.00", "percent_used": "112.0" }
  ]
}
```
`quoted_revenue`, `budget`, and the three attention money fields are nullable.
`tier` ∈ `"overrun" | "warning" | "incomplete"`.

`GET /api/v1/projects/{id}/financials`
```json
{ "project_id": "…", "name": "…", "status": "active",
  "breakdown": { "categories": [{"category_id","category_name","total"}],
                 "labor": {"total","rated_seconds","unrated_seconds"},
                 "labor_tracked_at_job_level": false, "grand_total": "40120.00",
                 "margin": {…}, "budget": {…} },
  "scopes": [ { "trade_scope_id": "…", "trade_name": "Plumbing",
                "spent": "8200.00", "budget": {…}|null } ] }
```
No `entries[]` — a chart page never downloads itemized rows.

`GET /api/v1/projects/{id}/financials/trend?window=12m` (`window` ∈ `3m|6m|12m|all`, default `12m`)
```json
{ "project_id": "…", "window": "12m",
  "buckets": [ { "month": "2026-03", "cost": "12000.00", "margin": {…MarginSummary…} } ] }
```
