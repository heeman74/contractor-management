<objective>
Ship `GET /api/v1/financials/company`: one batched read path that produces every
project's cost, margin and budget block plus portfolio totals and the ordered
attention list, in a constant number of round trips.

Purpose: this endpoint is the company overview's only data source and the phase's
single hardest constraint (CLAUDE.md's no-query-in-a-loop rule at company scale).
Calling `rollup_for_project` per project would be 7×N round trips and would fail
the D-03 budget outright.
Output: `PortfolioRepository`, `PortfolioService`, response schemas, the gated
route, and six named backend tests including the equivalence pin.
</objective>

**Wire contract (must match plan 35-04's web types byte-for-byte):**
```json
GET /api/v1/financials/company ->
{ "portfolio": { "cost", "quoted_revenue"|null, "incomplete_project_count",
                 "margin": MarginSummary },
  "projects": [ { "project_id","name","status","cost","margin": MarginSummary,
                  "budget": BudgetVsActual|null } ],
  "attention": [ { "project_id","project_name","project_status","tier",
```

project's grand_total. Scope budgets surface through `attention[]` (anchor_label
