<objective>
Ship `GET /api/v1/projects/{project_id}/financials/trend?window=`: dense monthly
cumulative buckets produced by replaying the shipped Phase 33 margin pipeline at
each month-end edge.

Purpose: D-01/D-02's margin trend, with a self-verifying property — the final
bucket must be bit-identical to `rollup_for_project`'s margin block. That
reconciliation is worth more than any amount of hand-checking bucket arithmetic,
and it is the reason the as-of replay was chosen over delta accumulation.
Output: dated document queries, the trend service method, the gated windowed
route, and five named tests.
</objective>

**Wire contract (must match plan 35-04's `MarginTrend` type):**
```json
GET /api/v1/projects/{project_id}/financials/trend?window=12m ->
{ "project_id": "…", "window": "12m",
  "buckets": [ { "month": "2026-03", "cost": "12000.00", "margin": MarginSummary } ] }
```
`window` ∈ `3m | 6m | 12m | all`, default `12m`; an unknown value is a 422.
`buckets` is ascending by month and dense (no gaps).

**From plan 35-01 (`trend_math.py`, DB-free):**


**Pitfall 4 (locked resolution):** `Quote.approved_at` is nullable even for
status `approved`. Bucket by `COALESCE(approved_at, created_at)` — never exclude
such a quote, because excluding it breaks the final-bucket reconciliation that is
the trend's only self-check.
