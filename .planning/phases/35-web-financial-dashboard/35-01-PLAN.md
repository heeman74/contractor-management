  <behavior>
    - Bucket key is `"YYYY-MM"` (UTC); a bucket's edge is that month's last calendar day, inclusive.
    - Buckets are dense: every month from the earliest dated record's month through `today`'s month, with no gaps, values carried forward cumulatively.
    - A cost entry contributes to every bucket whose edge >= its `incurred_date`.
    - A work session contributes to every bucket whose edge >= `work_date_for(clocked_in_at)`.
    - An invoice contributes revenue to every bucket whose edge >= the UTC date of `issued_at`.
    - An approved quote contributes to every bucket whose edge >= the UTC date of `approved_at`, falling back to `created_at` when `approved_at` is None (Pitfall 4).
    - Revenue per bucket is RESOLVED (never accumulated): `combined_anchor_revenue(anchor_revenues(invoices<=edge, quotes<=edge))`, with the project-level fallback quote used only when no anchor resolved anything.
    - With `today` as the final edge and the full record set, the final bucket's MarginFigures equals what `FinanceService._project_margin` produces for the same data.
    - `window_slice` returns the LAST N buckets and never filters input records: any month present in a 3m and a 12m result carries identical values (Pitfall 2).
    - Empty inputs produce zero buckets (not a fabricated $0 month).
  </behavior>
