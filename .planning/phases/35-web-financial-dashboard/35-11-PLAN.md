<objective>
Ship the browser half of SC3 and the render proof for both routes: nav-item
absence without permission, a deny panel plus zero financial requests on a cold
direct load, and a permitted user reaching both dashboards by SPA navigation.

Purpose: SC3 says a user without `finance.*` does not see the Financials nav item
or any financial dashboard route at all. The naive version of this test is a
false green — a hard `page.goto` resets Redux, so `usePermissions` is disabled and
the deny panel renders for a PERMITTED user too, meaning the test would keep
passing with the gate deleted. Splitting the assertion (nav absence + a request
count of zero) is what gives it teeth.
