## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, dependency type badge internal padding, arrow stroke gap |
| sm | 8px | Compact list item padding, Gantt lane header padding (8px per side), conflict badge gap |
| md | 16px | Default element spacing, dialog body padding, form field gap |
| lg | 24px | Section padding, Gantt lane height baseline |
| xl | 32px | Layout gaps between Gantt and sidebar panels |
| 2xl | 48px | Gantt lane row minimum height (header strip + task bar + breathing room) |
| 3xl | 64px | Page-level spacing, Gantt page top padding |

Exceptions:
- Touch targets on mobile Gantt: minimum 44px height per task bar (WCAG 2.5.5 AA)
- Today line: 2px vertical stroke — not a spacing token, a visual marker
- Gantt task bar corner radius: 4px (xs token applied to border-radius)
- Mobile drag-to-connect tap target: minimum 44x44px handle at task bar right edge
- Gantt lane padding: 8px (sm token) per side top and bottom. Total vertical padding per lane = 16px (sm top + sm bottom). The former 12px value is replaced — 12px is not in the standard set.

## Interaction Contract

### Web Gantt Interactions

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Drag task bar | Mouse drag on task bar | Reschedule task — updates `start_date` and `due_date` optimistically; PATCH to API on drop |
| Drag-connect dependency | Drag from task bar right-edge handle to another task | Ghost arrow follows cursor; on drop: opens DependencyTypeSelect popover to confirm type + lag; POST to API; if cycle: dismiss popover, open CycleErrorDialog |
| Click task bar | Single click | Opens task detail panel in right sidebar (slide-in Sheet) |
| Zoom | Mouse wheel / zoom control buttons | Day / Week / Month scale. Default: Week. Three zoom levels only |
| Conflict badge click | Click ConflictBadge | Expands inline: "Electrical and Plumbing overlap in Kitchen on Mar 25. Click tasks to reschedule." |
| Remove dependency | Right-click dependency arrow | Context menu with single option "Remove dependency" → confirmation inline popover |
| Add zone | Zone manage button (above Gantt) | Opens ZoneManageModal — inline list with text input and "Add Zone" button |

### Mobile Gantt Interactions

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Pan | One-finger drag | Horizontal time scroll + vertical trade lane scroll |
| Zoom | Pinch (InteractiveViewer) | Scale 0.5x (month view) to 3.0x (day view); default 1.0x (week view) |
| Tap task bar | Single tap | Navigate to task detail screen |
| Long-press drag-connect | Long press on task bar right edge, then drag to target | Ghost arrow follows finger; release on target task bar → bottom sheet opens with FS/SS/FF/SE selector + lag input + "Create Dependency" button |
| Blocked start button | Contractor taps "Start Task" on blocked task | Button is disabled + greyed out; tapping shows snackbar: "This task is blocked. Complete [predecessor name] first." |

### Blocked State Contract

- **Web:** Blocked tasks show red StatusBadge in ProjectTree and red-filled bar in Gantt. "Start Task" button is absent from task detail panel for GC view. Tooltips on hover: "Blocked by: [predecessor task name]"
- **Mobile:** Blocked task cards show red "Blocked" chip. "Start" button is `enabled: false` with grey fill and reduced opacity (0.38). Tap shows snackbar per above. Contractors cannot override.

## State Definitions

### Task Bar States (Gantt)

| State | Visual Treatment |
|-------|-----------------|
| not_started | Gray bar `bg-gray-200`, 0% progress fill |
| in_progress | Amber bar `bg-amber-200`, progress fill `bg-amber-500` at completion % |
| complete | Green bar `bg-green-200`, progress fill `bg-green-600` at 100% |
| blocked | Red bar `bg-red-200`, dashed border `border-dashed border-red-400`, lock icon at left edge |
| conflict | Yellow border `border-2 border-yellow-400`, warning icon overlay at top-right of bar |
| cycle-involved | Red border `border-2 border-red-500 bg-red-50`, applies to ALL bars in the cycle path |

### Dependency Arrow States

| State | Visual Treatment |
|-------|-----------------|
| Normal FS | Dark gray bezier arrow `#374151`, arrowhead at target |
| SS / FF / SE | Same gray, label chip on arrow midpoint showing "SS", "FF", or "SE" |
| With lag | Label chip on arrow midpoint showing "+Nd" (lag) or "-Nd" (lead) |
| Cycle-involved | Red arrow `#ef4444`, 2px stroke weight, animated dash (CSS animation, web only) |
| Ghost (in-progress drag) | Dashed gray `#9ca3af`, 1px stroke, follows cursor/finger |

## Zone Management UI

Zone list is managed via a modal dialog (not inline on the Gantt). GC accesses it via a "Manage Zones" button in the Gantt page toolbar.

**ZoneManageModal layout:**
- Header: "Project Zones"
- Body: scrollable list of existing zones. Each row: zone name (text) + delete icon button (trash, red on hover, `aria-label="Delete [zone name]"`)
- Footer: text input ("Zone name") + "Add Zone" button (accent indigo)
- Zone names are display-only after creation — no inline rename to keep the interaction simple
- Validation: duplicate zone names show inline error "A zone with this name already exists" below the input

## Focal Point Declaration

**Gantt page primary visual anchor:** Task bars rendered within trade swim lanes are the focal point of the GanttPage. The swim lane grid (horizontal lanes colored by trade, with task bars as horizontal rectangles showing progress fill) is the dominant visual element. All other elements — the sidebar panel, the toolbar, the today line, the conflict badges — are secondary and must not compete visually with the task bars.

Implementation note: Gantt task bars should have sufficient contrast against lane background (minimum 3:1 for non-text UI components per WCAG 1.4.11). Lane row alternating background (`#f7f7f7`) ensures task bars (`bg-amber-200`, `bg-green-200`, `bg-red-200`, `bg-gray-200`) are perceptually distinct.

## Accessibility Requirements

| Requirement | Implementation |
|-------------|---------------|
| Gantt keyboard navigation (web) | Arrow keys navigate between task bars; Enter opens task detail; focus ring visible at all times |
| Blocked button state | `disabled` attribute set on "Start" button; not just visual styling |
| Color not sole indicator | All status states pair color with a label (StatusBadge text) or icon (lock on blocked bar) |
| Conflict badge | Uses `role="alert"` and `aria-live="polite"` to announce new conflicts |
| Cycle error dialog | Focus traps inside dialog; Escape closes; `role="alertdialog"` |
| Touch target minimum | 44x44px on all mobile interactive elements including drag handles |
| Today line | Has `aria-label="Today"` on its SVG/Canvas element or adjacent DOM label |
| ZoneManageModal trash icon | `aria-label="Delete [zone name]"` — label is dynamic, includes the zone name for screen reader context |
