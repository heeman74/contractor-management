Transform API data into SVAR Gantt format:
- Trade scopes become summary tasks (parent rows) with `type: "summary"` and `color` set to `scope.trade_color`
- Tasks become child rows under their scope with `parent: scope.id`
- Task start = `new Date(task.start_date || task.due_date || task.created_at)`
- Task end = `new Date(task.due_date || task.created_at)`
- Task progress = `status === 'complete' ? 100 : status === 'in_progress' ? 50 : 0`

Dependencies become SVAR links:
- `id: dep.id`, `source: dep.predecessor_task_id`, `target: dep.successor_task_id`, `type: dep.dependency_type`

Add `taskStyle` callback for conflict/cycle highlighting:
- Conflicting task IDs get yellow border: `{ border: "2px solid #f59e0b", background: "#fef3c7" }`
- Cycle-involved IDs get red border: `{ border: "2px solid #ef4444", background: "#fee2e2" }`

Handle SVAR events:
- `onLinkAdd` — opens DependencyTypeSelect popover, then calls `onDependencyCreate`
- `onTaskUpdate` — calls `onTaskUpdate` for reschedule

Add zoom controls: Day / Week / Month buttons. Default: Week.
Add today line styling if SVAR supports it (check docs).

Wrap in `dynamic(() => import(...), { ssr: false })` if SSR issues occur.
