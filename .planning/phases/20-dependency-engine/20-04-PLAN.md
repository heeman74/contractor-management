**2. Create gantt_painter.dart:**

```dart
class GanttPainter extends CustomPainter {
  final List<TradeScope> scopes;
  final Map<String, List<ProjectTask>> tasksByScope;
  final DateTime startDate;  // leftmost date on the time axis
  final int visibleDays;     // number of days visible at current zoom
  final double dayWidth;     // pixels per day (varies with zoom)
  final double laneHeight;   // 48px per lane (2xl spacing token)

  GanttPainter({
    required this.scopes,
    required this.tasksByScope,
    required this.startDate,
    required this.visibleDays,
    required this.dayWidth,
    this.laneHeight = 48.0,
  });

  @override
  void paint(Canvas canvas, Size size) {
    _drawTimeAxis(canvas, size);      // horizontal day/week labels at top
    _drawTodayLine(canvas, size);     // vertical gray-500 line at today's x position
    _drawSwimLanes(canvas, size);     // alternating bg (#f7f7f7 / white), trade color header strip
    _drawTaskBars(canvas, size);      // horizontal bars positioned by start_date -> due_date
  }
}
```

**Swim lanes:** Each TradeScope gets one horizontal lane. Header strip (left side, ~120px wide) shows trade name (16px semibold) with trade_color background. Lane rows alternate white / #f7f7f7.

**Task bars:** Horizontal rectangles within their lane. X position = `(task.startDate - startDate).inDays * dayWidth`. Width = `(task.dueDate - task.startDate).inDays * dayWidth` (min 1 day width). If startDate is null, derive from `dueDate - estimatedHours/8`.

**Bar colors by status:**
- not_started: `Color(0xFFE5E7EB)` (gray-200), 0% progress
- in_progress: `Color(0xFFFDE68A)` (amber-200), progress fill `Color(0xFFF59E0B)` (amber-500) at estimated % or 50%
- complete: `Color(0xFFBBF7D0)` (green-200), fill `Color(0xFF16A34A)` (green-600) at 100%
- blocked: `Color(0xFFFECACA)` (red-200), dashed border `Color(0xFFF87171)` (red-400), lock icon drawn at left edge

**Bar text:** Task title inside bar (14px regular, clipped to bar width).

**Today line:** Vertical 2px stroke at today's x position, color gray-500 (#6B7280).

**3. Create dependency_arrow_painter.dart:**

```dart
class DependencyArrowPainter extends CustomPainter {
  final List<TaskDependency> dependencies;
  final Map<String, Rect> taskBarRects;  // task ID -> painted rect position
  final Set<String> cycleInvolvedIds;    // task IDs involved in a cycle (red arrows)
  final Offset? dragStart;               // for ghost arrow during drag-to-connect
  final Offset? dragEnd;

  @override
  void paint(Canvas canvas, Size size) {
    for (final dep in dependencies) {
      final from = taskBarRects[dep.predecessorTaskId];
      final to = taskBarRects[dep.successorTaskId];
      if (from == null || to == null) continue;

      final paint = Paint()
        ..color = cycleInvolvedIds.contains(dep.predecessorTaskId)
            ? const Color(0xFFEF4444)  // red for cycle
            : const Color(0xFF374151)  // dark gray normal
        ..strokeWidth = cycleInvolvedIds.contains(dep.predecessorTaskId) ? 2.0 : 1.5
        ..style = PaintingStyle.stroke;

      // Draw bezier curve from right edge of predecessor to left edge of successor
      final startPoint = Offset(from.right, from.center.dy);
      final endPoint = Offset(to.left, to.center.dy);
      final ctrl1 = Offset(startPoint.dx + 20, startPoint.dy);
      final ctrl2 = Offset(endPoint.dx - 20, endPoint.dy);

      final path = Path()
        ..moveTo(startPoint.dx, startPoint.dy)
        ..cubicTo(ctrl1.dx, ctrl1.dy, ctrl2.dx, ctrl2.dy, endPoint.dx, endPoint.dy);
      canvas.drawPath(path, paint);

      // Draw arrowhead at endPoint
      _drawArrowhead(canvas, ctrl2, endPoint, paint);

      // Draw dependency type label chip at midpoint for SS/FF/SE
      if (dep.dependencyType != 'FS') {
        _drawTypeLabel(canvas, startPoint, endPoint, dep.dependencyType);
      }
      // Draw lag label if lag_days != 0
      if (dep.lagDays != 0) {
        _drawLagLabel(canvas, startPoint, endPoint, dep.lagDays);
      }
    }

    // Draw ghost arrow during drag-to-connect
    if (dragStart != null && dragEnd != null) {
      final ghostPaint = Paint()
        ..color = const Color(0xFF9CA3AF)  // gray-400
        ..strokeWidth = 1.0
        ..style = PaintingStyle.stroke;
      // Dash pattern using PathDashEffect or manual dash
      canvas.drawLine(dragStart!, dragEnd!, ghostPaint);
    }
  }
}
```

Build method:
```dart
@override
Widget build(BuildContext context) {
  return LayoutBuilder(
    builder: (context, constraints) {
      final canvasWidth = _computeCanvasWidth();
      final canvasHeight = scopes.length * 48.0 + 40.0; // 48px per lane + 40px header
      return InteractiveViewer(
        minScale: 0.5,
        maxScale: 3.0,
        constrained: false,
        child: GestureDetector(
          onTapUp: _handleTap,
          onLongPressStart: _handleLongPressStart,
          onLongPressMoveUpdate: _handleLongPressMove,
          onLongPressEnd: _handleLongPressEnd,
          child: SizedBox(
            width: canvasWidth,
            height: canvasHeight,
            child: RepaintBoundary(
              child: Stack(children: [
                CustomPaint(
                  painter: GanttPainter(...),
                  size: Size(canvasWidth, canvasHeight),
                ),
                CustomPaint(
                  painter: DependencyArrowPainter(
                    dependencies: widget.dependencies,
                    taskBarRects: _taskBarRects,
                    cycleInvolvedIds: {},
                    dragStart: _dragStartOffset,
                    dragEnd: _dragPosition,
                  ),
                  size: Size(canvasWidth, canvasHeight),
                ),
              ]),
            ),
          ),
        ),
      );
    },
  );
}
```
