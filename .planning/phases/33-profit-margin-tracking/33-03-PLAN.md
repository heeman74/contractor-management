    Algorithm (each numbered step a named local or small private method, no step inline-nested):
    1. `revenue_repository = RevenueRepository(self.db)`; fetch
       `invoice_amounts_by_anchor_for_project(project_id)` and, ONLY if that returned no rows,
       `approved_quote_amounts_by_anchor_for_project(project_id)`. Two bounded queries max —
       D-01 applied at project scale: if the project has any invoice at all, no quote leg is needed
       for anchors that lack one either, because a quote at an anchor with no invoice still counts;
       therefore fetch the quote rows whenever ANY anchor could lack an invoice — i.e. always fetch
       both, and let `_anchor_revenues` discard quotes at invoiced anchors. (Two queries, fixed cost.)
    2. `anchor_revenues = _anchor_revenues(invoice_rows, quote_rows)`.
    3. `resolved_totals = [r for r in anchor_revenues.values() if r.total is not None]`.
    4. D-14 fallback: when `resolved_totals` is empty, call
       `latest_project_level_approved_quote_amounts(project_id)`; if present, revenue is its
       `pre_tax_total(...)` with basis `REVENUE_BASIS_QUOTED`, else `ResolvedRevenue(None, REVENUE_BASIS_NONE)`.

       the anchor of last resort — it counts only when NO anchor in the project resolved any
       revenue. Any invoice anywhere in the project makes an anchor revenue-bearing, satisfying
       D-14's "entire project has zero invoices" condition, while also preventing a project quote
       from being added on top of the per-scope quotes it spawned. Document this in the method
