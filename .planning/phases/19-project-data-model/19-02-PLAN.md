Create four DAOs as `@DriftAccessor` classes following the `user_dao.dart` pattern:

**ProjectDao** (`@DriftAccessor(tables: [Projects, SyncQueue])`):
- `Stream<List<Project>> watchProjectsByCompany(String companyId)` — select where companyId equals and deletedAt is null, ordered by createdAt desc
- `Future<Project?> getProjectById(String id)` — single select by id
- `Future<void> insertProject(ProjectsCompanion entry)` — transaction: insert project + sync queue entry (entityType: 'project', operation: 'CREATE')
- `Future<void> updateProject(String id, ProjectsCompanion entry)` — transaction: update by id + sync queue entry (operation: 'UPDATE')
- `Future<void> softDeleteProject(String id)` — transaction: update deletedAt to now + sync queue entry (operation: 'DELETE')

**TradeCatalogDao** (`@DriftAccessor(tables: [TradeCatalogEntries, SyncQueue])`):
- `Stream<List<TradeCatalogEntry>> watchCatalogByCompany(String companyId)` — watch all non-deleted, ordered by name
- `Future<void> insertCatalogEntry(TradeCatalogEntriesCompanion entry)` — transaction with sync queue
- `Future<void> updateCatalogEntry(String id, TradeCatalogEntriesCompanion entry)` — transaction with sync queue

**TradeScopeDao** (`@DriftAccessor(tables: [TradeScopes, SyncQueue])`):
- `Stream<List<TradeScope>> watchScopesByProject(String projectId)` — watch where projectId equals, deletedAt null, ordered by sortOrder
- `Future<void> insertScope(TradeScopesCompanion entry)` — transaction with sync queue
- `Future<void> updateScope(String id, TradeScopesCompanion entry)` — transaction with sync queue
- `Future<void> softDeleteScope(String id)` — transaction with sync queue

**TaskDao** (`@DriftAccessor(tables: [ProjectTasks, SyncQueue])`):
- `Stream<List<ProjectTask>> watchTasksByScope(String tradeScopeId)` — watch where tradeScopeId equals, deletedAt null, ordered by sortOrder
- `Future<int> countTasksByScope(String tradeScopeId)` — count non-deleted
- `Future<int> countCompletedTasksByScope(String tradeScopeId)` — count where status='complete' and not deleted
- `Future<void> insertTask(ProjectTasksCompanion entry)` — transaction with sync queue
- `Future<void> updateTask(String id, ProjectTasksCompanion entry)` — transaction with sync queue
- `Future<void> softDeleteTask(String id)` — transaction with sync queue

For sync queue entries, use the `_buildQueueEntry` helper pattern from user_dao.dart. Entity type strings: 'project', 'trade_catalog', 'trade_scope', 'task'.

Create four sync handlers following `company_sync_handler.dart` pattern:

**ProjectSyncHandler**: entityType='project', push to '/projects', applyPulled using `ProjectsCompanion` + `insertOnConflictUpdate`

**TradeScopeSyncHandler**: entityType='trade_scope', push to '/trade-scopes', applyPulled using `TradeScopesCompanion`
**TaskSyncHandler**: entityType='task', push to '/tasks', applyPulled using `ProjectTasksCompanion`

Each sync handler maps snake_case server JSON keys to Dart camelCase Companion fields. Handle nullable fields with null checks. Parse datetime strings with `DateTime.parse()`.

**Update sync_registry.dart**: Register all four new handlers in the `_handlers` map alongside existing handlers. Follow the exact registration pattern used for CompanySyncHandler, UserSyncHandler, etc.
