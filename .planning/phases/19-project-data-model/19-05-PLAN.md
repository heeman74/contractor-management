**Create `web/src/lib/api/projects.ts`:**
API client functions using `apiFetch`:
- `fetchProjects(): Promise<ProjectResponse[]>` — GET /api/v1/projects/
- `fetchProject(id: string): Promise<ProjectResponse>` — GET /api/v1/projects/{id}
- `createProject(data: ProjectCreate): Promise<ProjectResponse>` — POST /api/v1/projects/
- `updateProject(id: string, data: Partial<ProjectCreate>): Promise<ProjectResponse>` — PATCH
- `fetchTradeCatalog(): Promise<TradeCatalogResponse[]>` — GET /api/v1/trade-catalog/
- `createTradeCatalogEntry(data: {name: string; color?: string}): Promise<TradeCatalogResponse>` — POST
- `fetchTradeScopes(projectId: string): Promise<TradeScopeResponse[]>` — GET /api/v1/trade-scopes/?project_id=
- `createTradeScope(data: TradeScopeCreate): Promise<TradeScopeResponse>` — POST
- `updateTradeScope(id: string, data: Partial<TradeScopeCreate>): Promise<TradeScopeResponse>` — PATCH
- `fetchTasks(tradeScopeId: string): Promise<TaskResponse[]>` — GET /api/v1/tasks/?trade_scope_id=
- `createTask(data: TaskCreate): Promise<TaskResponse>` — POST
- `fetchContractors(tradeCatalogId?: string): Promise<ContractorMatch[]>` — GET /api/v1/contractors/?trade_catalog_id=

TanStack Query hooks:
- `useProjects()` — useQuery wrapping fetchProjects, key: ['projects']
- `useProject(id: string)` — useQuery wrapping fetchProject, key: ['projects', id]
- `useTradeCatalog()` — useQuery wrapping fetchTradeCatalog, key: ['trade-catalog']
- `useTradeScopes(projectId: string)` — useQuery wrapping fetchTradeScopes, key: ['trade-scopes', projectId]
- `useTasks(tradeScopeId: string)` — useQuery wrapping fetchTasks, key: ['tasks', tradeScopeId]
- `useContractors(tradeCatalogId?: string)` — useQuery wrapping fetchContractors
