**Create `backend/app/features/projects/service.py`:**

**ProjectService** (TenantScopedService[Project]):
- `repository_class = ProjectRepository`
- Override `async def create(self, data: ProjectCreate) -> Project:` — create Project instance with company_id from `_require_tenant_id()`, status='draft', status_history=[{"status": "draft", "changed_at": now().isoformat(), "changed_by": str(user_id)}]
- `async def update_status(self, project_id: uuid.UUID, new_status: str, user_id: uuid.UUID) -> Project:` — get project, validate new_status is valid, append to status_history, update status, flush
- `async def get_with_scopes(self, project_id: uuid.UUID) -> Project:` — delegate to repository

**TradeScopeService** (TenantScopedService[TradeScope]):
- `repository_class = TradeScopeRepository`
- Override `async def create(self, data: TradeScopeCreate, user_id: uuid.UUID) -> TradeScope:` — create scope, auto-assign sort_order as count+1, copy trade_color from catalog if trade_catalog_id provided, then check project status: if 'draft', auto-advance to 'planning' with status_history entry. Use `db.flush()` after both writes.

**TaskService** (TenantScopedService[Task]):
- `repository_class = TaskRepository`
- Override `async def create(self, data: TaskCreate) -> Task:` — create task, auto-assign sort_order

**Create `backend/app/features/projects/router.py`:**

Create an `APIRouter` with prefix `/api/v1`. Register sub-routers:

1. **Projects router** (`/projects`):
   - `POST /` — create project (requires auth)
   - `GET /` — list projects with trade_scopes eager-loaded
   - `GET /{project_id}` — get project detail with trade_scopes
   - `PATCH /{project_id}` — update project (if status in data, call update_status)
   - `DELETE /{project_id}` — soft delete

2. **Trade Catalog router** (`/trade-catalog`):
   - `POST /` — create catalog entry
   - `GET /` — list catalog entries
   - `PATCH /{id}` — update (name, color)
   - `DELETE /{id}` — soft delete

3. **Trade Scopes router** (`/trade-scopes`):
   - `POST /` — create scope (passes current_user['user_id'] to service for status history)
   - `GET /` — list by project_id query param (required)
   - `PATCH /{id}` — update (contractor_id, status, status_override)
   - `DELETE /{id}` — soft delete

4. **Tasks router** (`/tasks`):
   - `POST /` — create task
   - `GET /` — list by trade_scope_id query param (required)
   - `PATCH /{id}` — update task
   - `DELETE /{id}` — soft delete

5. **Contractor specialty endpoint** (`/contractors`):
   - `GET /?trade_catalog_id={id}` — query all users with contractor role in current company, LEFT JOIN user_trade_specialties, ORDER BY specialty match DESC then name ASC. Return list of {id, name, email, has_specialty_match: bool}.

All route handlers use `Depends(get_current_user)` for auth. All use `Depends(get_db)` for database session.

**Update `backend/app/main.py`:** Import the router from projects and add `app.include_router(projects_router)`.
