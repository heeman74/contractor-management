## Layout Contracts

### Web: Project List Page (`/projects`)

Two-panel layout: left sidebar tree (collapsible, 280px) + right detail panel (flex-1).

```
[Global Sidebar 60px/240px] | [Project Tree 280px] | [Detail Panel flex-1]
```

- Project tree sidebar: collapsible list of projects, each expandable to show trade scopes, each expandable to show tasks. File-explorer pattern using `ChevronRight`/`ChevronDown` icons (lucide-react).
- Clicking a project node: loads project detail in right panel (name, status badge, address, client, dates, trade scope count).
- Clicking a trade scope node: loads trade scope detail (trade name + color swatch, contractor name, task progress bar, task count, status badge).
- Clicking a task node: loads task detail (title, description, priority badge, due date, materials list, assigned contractor).
- Default state: first project selected and its detail shown. No node selected shows empty state.
- Tree node active state: `bg-indigo-50 text-indigo-700 font-medium` (matching existing sidebar active pattern).

### Web: Create Project Dialog

Full-width `Dialog` (max-w-lg). Fields in order:
1. Project Name (required) — `Input`
2. Description — `Textarea` (3 rows)
3. Address — `Input`
4. Client — `Select` (searchable, pulls from existing CRM clients)
5. Target Start Date — `Calendar` in `Popover`
6. Target End Date — `Calendar` in `Popover`

Footer: "Cancel" (ghost) + "Create Project" (default/indigo) buttons.

### Web: Trade Scope Assignment Sheet

Triggered from project detail panel "Add Trade Scope" button. Uses a right-side `Sheet` (not full dialog) to maintain project context visible behind it.

Fields:
1. Trade name — combobox: search catalog first, fallback to ad-hoc text entry. Matching catalog entries shown with color swatch. Non-matching text entry shows "Create new trade: {name}" option at bottom.
2. Contractor — `Select` with specialty-sorted list. Contractors with matching specialty shown first with "(Specialty match)" label. All others listed below a divider.
3. Sort order — hidden (auto-assigned as next integer).

"Save to catalog?" prompt: If trade name is ad-hoc (no catalog match), show inline `Alert` below trade field: "'{name}' is not in your trade catalog. Save to catalog for future projects?" with "Save to Catalog" button (outline) and "Use Once" link.

### Mobile: Project List Screen

Standard scrollable list. Each project row: project name (text-sm semibold) + status badge + address truncated to 1 line (text-xs muted) + "N scopes" count (text-xs). Tap to navigate to project detail.

Floating action button (FAB): `+` button, bottom-right, 56px, indigo-600 fill, opens create project bottom sheet.

### Mobile: Project Detail Screen (Trade Scope Cards)

Screen title: project name. Status badge inline in header. Below header: scrollable list of `TradeScope` cards.

Each card (matches CONTEXT.md decision):
- Left: 12px color swatch dot (trade catalog color) + trade name (text-sm semibold)
- Below name: contractor name or "Unassigned" in muted text-xs
- Right: "3/8 tasks" count (text-xs) + status badge (text-xs)
- Bottom: thin 4px progress bar, full card width, trade color fill, bg-gray-100 track

Card tap: navigates to trade scope detail (task list).

### Mobile: Task List Screen

Screen title: trade scope trade name. Scrollable list of tasks.

Each task row: priority indicator (left border 4px: urgent=red, high=orange, medium=blue, low=gray) + task title (text-sm) + status badge (text-xs) + due date (text-xs muted). Tap: opens task detail sheet.

## Interaction Contracts

### Status Badge — GC Manual Override

Trade scope status can be manually overridden by the GC. The status badge on the trade scope detail panel is clickable (GC role only). Clicking it opens a `Select` dropdown with the four valid states. Selecting a different state shows a brief confirmation inline ("Override status to {new status}? This will ignore task completion %.") with "Confirm" + "Cancel" inline buttons (no dialog needed — low-risk action).

### Ad-Hoc Trade Entry Combobox

1. GC types in trade name field.
2. Matching catalog entries appear as suggestions with color swatch.
3. If no match: "Create new trade: {typed text}" appears as last option with `Plus` icon.
4. Selecting "Create new trade" sets the trade name and reveals the "Save to catalog?" `Alert` inline below the field.
5. "Save to Catalog": creates catalog entry (name + auto-assigned color) and links scope to it. Color is editable later from catalog settings.
6. "Use Once": creates scope with `trade_catalog_id: null`, `trade_name` set to typed text.

### Contractor Picker — Specialty Sorting

1. Contractors with at least one specialty matching the selected trade catalog entry appear first in the `Select` dropdown.
2. A non-interactive separator label "Other Contractors" separates them from unmatched contractors.
3. If no trade catalog entry (ad-hoc trade, `trade_catalog_id: null`): no specialty sorting — all contractors in alphabetical order.
4. Contractor display name format: "{Full Name} — {role}" (e.g., "John Smith — Contractor").

### Project Tree (Web) — Expand/Collapse

- Tree nodes use `ChevronRight` (collapsed) / `ChevronDown` (expanded) from lucide-react, 16px, `text-gray-400`.
- Expand/collapse is per-node and persists in local React state for the session (no backend persistence needed).
- Keyboard: `Enter`/`Space` toggles expand; `ArrowRight`/`ArrowLeft` expands/collapses.
- Active node (currently shown in detail panel): highlighted `bg-indigo-50 text-indigo-700`.

### Mobile Bottom Navigation — Projects Tab

New "Projects" tab added to `AppShell` bottom navigation. Position: between "Jobs" and the next existing tab (exact position is executor's discretion based on current tab order). Visible to `admin` (GC) and `contractor` roles; hidden for `client` role. Icon: `Icons.folder_outlined` (inactive), `Icons.folder` (active). Label: "Projects".
