   ```python
   class ImageUploadResponse(BaseResponseSchema):
       conversation_id: uuid.UUID
       original_filename: str
       media_type: str
       file_size_bytes: int
   ```

4. Add image upload endpoint to `backend/app/features/ai/router.py`:

   **POST /ai/intake/image** — Upload an image for Claude vision:
   - Params: `file: UploadFile`, `conversation_id: uuid.UUID = Form(...)`
   - Auth: get_current_user, get_db
   - Validate: file content_type starts with "image/" (reject non-images)
   - Validate: file size <= 10MB raw (before compression)
   - Read file bytes, compress using Pillow:
     ```python
     from PIL import Image
     import io
     img = Image.open(io.BytesIO(file_bytes))
     # Resize to max 1280x1280 maintaining aspect ratio
     img.thumbnail((1280, 1280))
     # Convert to JPEG for consistency, quality=85
     buf = io.BytesIO()
     img.save(buf, format="JPEG", quality=85)
     compressed_bytes = buf.getvalue()
     ```
   - Save compressed file via aiofiles to `uploads/ai_images/{conversation_id}/{uuid}.jpg`
   - Create `AIImageUpload` record with file_path, original_filename, media_type="image/jpeg", file_size_bytes
   - Return `ImageUploadResponse` with the image's ID as `image_ref_id`

5. Add image vision method to `backend/app/features/ai/service.py`:

   **`async def build_image_content_block(self, image_ref_id: uuid.UUID) -> dict | None`**
   - Look up AIImageUpload by id
   - Read file from disk via aiofiles
   - Base64 encode the bytes
   - Return Claude vision content block:
     ```python
     {
         "type": "image",
         "source": {
             "type": "base64",
             "media_type": "image/jpeg",
             "data": base64_data,
         }
     }
     ```
   - Return None if image not found

6. Update the message flow in router.py intake/message and interview/message endpoints:
   - If `req.image_ref_id` is not None:
     - Call `service.build_image_content_block(req.image_ref_id)`
     - Build user message content as a list: `[image_block, {"type": "text", "text": req.message}]`
     - Pass this list content (not plain string) to `persist_user_message`
   - The existing `persist_user_message` already accepts `str | list` for content
