5. Create `backend/app/features/ai/service.py`:

   ```python
   from anthropic import AsyncAnthropic
   from collections.abc import AsyncIterable
   from fastapi.sse import ServerSentEvent
   import json

   _anthropic_client = AsyncAnthropic()  # reads ANTHROPIC_API_KEY from env

   class AIService(TenantScopedService[AIConversation]):
       repository_class = AIConversationRepository

       def __init__(self, db: AsyncSession) -> None:
           super().__init__(db)
           self._message_repo = AIMessageRepository(db)
           self._usage_repo = AITokenUsageRepository(db)
   ```

   Key methods:

   **`async def get_or_create_conversation(self, project_id, scope_id, conv_type, user_id) -> AIConversation`**
   - Look up active conversation for project+type or scope
   - If found, return it. If not, create new AIConversation with status='active'

   **`async def load_conversation_context(self, conversation_id, user_id) -> tuple[AIConversation, list[dict], str]`**
   - Fetch conversation (verify ownership via user_id or company_id)
   - Fetch all AIMessage rows for this conversation via `_message_repo.list_by_conversation()`
   - Build `messages: list[dict]` in Claude API format: `[{"role": msg.role, "content": msg.content_json}]`
   - Build system prompt by formatting the appropriate template (intake or interview) with trade catalog, project context
   - Return (conversation, messages, system_prompt)

   **`async def persist_user_message(self, conversation_id, content: str | list, user_id) -> AIMessage`**
   - Create AIMessage with role='user', content_json=content (string wraps to `[{"type":"text","text":content}]`), next sequence_num
   - flush + return

   **`async def persist_assistant_message(self, conversation_id, content_blocks: list) -> AIMessage`**
   - Create AIMessage with role='assistant', content_json=content_blocks (full Claude content array including tool_use blocks), next sequence_num

   **`async def persist_tool_result(self, conversation_id, tool_use_id: str, result: str) -> AIMessage`**
   - Create AIMessage with role='user', content_json=[{"type":"tool_result","tool_use_id":tool_use_id,"content":result}]

   **`async def record_usage(self, conversation_id, user_id, model, input_tokens, output_tokens)`**
   - Create AITokenUsage record

   **`async def stream_turn(self, conversation: AIConversation, messages: list[dict], system_prompt: str, tools: list[dict]) -> AsyncIterable[ServerSentEvent]`**
   - This is an async generator. It calls `_anthropic_client.messages.stream()` with model="claude-sonnet-4-6", max_tokens=4096, system=system_prompt, tools=tools, messages=messages
   - Inside `async with client.messages.stream(...) as stream:`, iterate events:
     - On `content_block_delta` with `text_delta`: yield `ServerSentEvent(data=json.dumps({"delta": event.delta.text}), event="token")`
   - After stream completes, call `await stream.get_final_message()` to get the complete message
   - Emit tool_call events: for each content block with type=="tool_use", yield `ServerSentEvent(data=json.dumps({"tool": block.name, "input": block.input, "id": block.id}), event="tool_call")`
   - Yield `ServerSentEvent(data=json.dumps({"stop_reason": final_msg.stop_reason}), event="done")`
   - Return final_msg (caller uses it for persistence)

   **`async def validate_tool_input(self, tool_name: str, tool_input: dict) -> dict`**
   - For "create_trade_scope": validate tool_input has trade_name (str, non-empty) and sort_order (int). Return cleaned dict.
   - For "create_task": validate tool_input has title (str, non-empty, max 300) and sort_order (int). Optional: description, priority (must be in low/medium/high/urgent), estimated_hours (number >= 0), materials_needed (list of dicts).
   - For "ask_clarifying_question": validate tool_input has question (str, non-empty). Return cleaned dict.
   - Raise ValueError with descriptive message on invalid input.

   **`async def mark_complete(self, conversation_id: uuid.UUID) -> None`**
   - Update conversation status to 'complete'

   **`async def mark_abandoned(self, conversation_id: uuid.UUID) -> None`**
   - Update conversation status to 'abandoned'

   Add retry logic as a private method `_call_with_retry` that wraps the anthropic call with exponential backoff (3 attempts, 1s/2s/4s delays). On persistent failure, yield an error SSE event: `ServerSentEvent(data=json.dumps({"message":"Something went wrong. Please try again."}), event="error")`.
