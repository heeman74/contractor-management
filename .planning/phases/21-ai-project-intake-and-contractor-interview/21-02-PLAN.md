   **POST /ai/intake/start** — Start or resume an intake conversation:
   - Params: `project_id: uuid.UUID | None = None` (query param, optional for new projects)
   - Auth: `current_user = Depends(get_current_user)`, `db = Depends(get_db)`
   - Create AIService(db), call `get_or_create_conversation(project_id=project_id, scope_id=None, conv_type="intake", user_id=current_user.user_id)`
   - If conversation already has messages, load them and return `{"conversation_id": conv.id, "messages": [...], "status": conv.status}` (for re-entry D-06)
   - Return `ConversationResponse.model_validate(conv)` with status 201 for new, 200 for existing

   **POST /ai/intake/message** — Send a message in an intake conversation (SSE streaming):
   - Body: `ChatTurnRequest`
   - Auth: get_current_user, get_db
   - Load conversation context via `service.load_conversation_context(req.conversation_id, current_user.user_id)`
   - If conversation status != 'active', return 400 "Conversation is not active"
   - Persist user message via `service.persist_user_message(req.conversation_id, req.message, current_user.user_id)`
   - Build messages list from loaded context + new user message
   - Return `EventSourceResponse(service.stream_turn(conversation, messages, system_prompt, INTAKE_TOOLS))`
   - IMPORTANT: response_class=EventSourceResponse in decorator

   **POST /ai/intake/complete** — Mark intake conversation complete and create trade scopes:
   - Body: `{"conversation_id": uuid, "trade_scopes": [{"trade_name": str, "trade_color": str, "sort_order": int}], "project_name": str, "project_description": str | None}`
   - This is where the GC's edited preview is committed to the DB
   - Create project via ProjectService if project_id is None, else use existing
   - For each trade scope in the list: call TradeScopeService.create() with project_id
   - Mark conversation complete via `service.mark_complete()`
   - Return `{"project_id": project.id, "trade_scope_ids": [...]}`

   **POST /ai/interview/start** — Start interview for a trade scope:
   - Params: `scope_id: uuid.UUID` (required)
   - Auth: get_current_user, get_db
   - Verify scope exists and current user is the assigned contractor (or is admin/GC)
   - Create conversation with conv_type='interview', scope_id=scope_id
   - Return ConversationResponse

   **POST /ai/interview/message** — Send message in interview (SSE streaming):
   - Same pattern as intake/message but uses INTERVIEW_TOOLS
   - Load project + all scopes context for system prompt injection (D-16)

   **POST /ai/interview/complete** — Accept task plan from interview:
   - Body: `{"conversation_id": uuid, "tasks": [{"title": str, "description": str | None, "priority": str, "estimated_hours": float | None, "sort_order": int, "materials_needed": list | None}]}`
   - Soft-delete existing tasks for scope if any (D-19 re-interview cleanup)
   - For each task: call TaskService.create() with trade_scope_id from conversation's scope
   - Mark conversation complete
   - Fire FCM push notification to project owner (GC): "{Trade Name} contractor completed interview - {N} tasks generated" (D-20)
   - Return `{"task_ids": [...]}`

   **GET /ai/conversations/{conversation_id}** — Get conversation with messages:
   - Return conversation + all messages for re-entry / transcript viewing
