## Typography

### Web (Geist Sans — inherits shadcn base-nova scale)

Two weights only: 400 (regular) and 600 (semibold).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Chat bubble message text, task card description |
| Label | 12px | 400 | 1.4 | Sender name above bubble, timestamp, badge text |
| Heading | 16px | 600 | 1.3 | Screen titles ("AI Intake", "Contractor Interview"), card section headers |
| Display | 20px | 600 | 1.2 | Page-level headings (full-page chat screen title) |

Note on 12px/14px: the Label vs Body distinction is semantic (metadata vs content), not purely size-driven. The 2px gap is intentional — both render at weight 400; Label items additionally use `text-muted-foreground` color to reinforce the hierarchy.

| Role | M3 Token | Size | Weight | Line Height | Usage |

| Label | `bodySmall` | 12px | 400 | 1.4 | Timestamps, sender name |
| Heading | `titleMedium` | 16px | 600 (w600) | 1.3 | Screen AppBar title, card section label |

## Primary Visual Focal Point

The chat message list is the primary visual anchor on both platforms. The user's eye should be drawn to the most recent message at the bottom of the list. Achieve this by:
- Web: the fixed bottom input bar draws the eye downward; the last message sits directly above it with md (16px) clearance.
- Mobile: the pinned `Container` with the `TextField` anchors the bottom; the `ListView` scrolls so the latest message is always the nearest element above the input.

The AI avatar (`ContractorHub AI` icon + label) beside each AI bubble is the secondary focal point — it communicates the AI persona and differentiates the two sides of the conversation.

## Interaction Contracts

### Chat Screen Layout

**Web** (`/projects/new/ai-intake` and `/projects/{id}/interview/{scopeId}`):
- Full-page layout (no sidebar overlap)
- Fixed header: screen title + back navigation
- Scrollable message list (`ScrollArea`) occupies remaining height — auto-scrolls to bottom on new token
- Fixed bottom: chat input (Textarea + send button + attach button)
- Preview card section appears below chat input after AI completes structured output — does NOT push messages up; the chat pane shrinks and preview pane appears below with a visible divider

**Mobile** (new screen from Projects tab and trade scope detail):
- `Scaffold` with `AppBar` showing context ("AI Intake — {project name}" or "Interview — {trade name}")
- `ListView` of messages fills body — `controller.animateTo(max)` on new token
- Bottom-pinned `Container` with `TextField` + send `IconButton` + attach `IconButton`
- After AI generates structured output: `DraggableScrollableSheet` opens from bottom (initial: 40% height, max: 80%), showing preview cards. Chat remains scrollable behind it.

### Streaming Token Display

- Tokens append to the current AI bubble character-by-character
- Bubble width expands naturally with text (no fixed width)
- `TypingIndicator` shows while SSE connection is open AND no first token received yet
- `TypingIndicator` disappears when first token arrives; bubble appears instead
- On `tool_call` SSE event: stop streaming display, show a transitional message in the AI bubble: "Generating your [trade breakdown / task plan]..."
- On `done` SSE event: preview card/list renders

### Offline State

- Detect connectivity before allowing send: check `navigator.onLine` (web) / `Connectivity` package (mobile)
- `OfflineBanner` appears above input, input disabled
- If connectivity drops mid-stream: show error bubble from AI: "Connection lost. Please check your internet connection and try again."
- Do NOT queue the request — discard and require manual retry (D-30)

### Image Upload Flow

- Attach button (paperclip) opens image picker (file picker on web, `ImagePicker` on mobile)
- Selected image shows as thumbnail preview attached to input area before send
- On send: image uploads to `/api/v1/ai/intake/image` first (separate endpoint), receives `image_ref_id`
- Image thumbnail appears in user's chat bubble
- Next AI turn includes the image context

### Re-interview Confirmation (D-19)

- "Restart Interview" button triggers `AlertDialog` / shadcn `Dialog`
- Title: "Restart Interview?"
- Body: "This will replace all [N] existing tasks for [Trade Name]. This cannot be undone."
- Actions: "Keep Current Plan" (outline) + "Restart Interview" (destructive — red)
- On confirm: mark old conversation `abandoned`, start new conversation

## States and Transitions

### Chat Screen States

| State | Trigger | Visual |
|-------|---------|--------|
| `idle` | Screen loads, no messages | Empty state illustration + heading + body copy |
| `user_typing` | User types in input | Input grows, send button enabled |
| `sending` | User taps Send | Input clears, user bubble appears, TypingIndicator shows |
| `streaming` | First SSE token received | TypingIndicator disappears, AI bubble appears and grows |
| `tool_executing` | `tool_call` SSE event | Streaming stops, transitional message shows in AI bubble |
| `preview_ready` | `done` SSE event after tool_use | Preview card/list renders; CTAs enabled |
| `offline` | Connectivity lost | OfflineBanner shows, input disabled |
| `error` | AI API error or network failure | Error bubble from AI with retry instruction |
| `complete` | "Create Project" or "Accept Plan" tapped | Navigate to project detail or trade scope detail |

### Preview Card States (TradeScopePreviewCard / TaskPreviewList)

| State | Visual |
|-------|--------|
| `loading` | Skeleton rows (3 placeholders) while tool_call executes |
| `ready` | Editable rows with drag handles; CTA enabled |
| `editing` | Inline edit field focused (web: click to edit; mobile: tap to edit) |
| `saving` | CTA shows loading spinner; rows become non-interactive |
| `saved` | Navigate away |

## Accessibility

- Chat bubbles must have accessible role labels: user bubbles include `aria-label="Your message"` (web) / `Semantics(label: "Your message")` (mobile)
- AI bubbles: `aria-label="ContractorHub AI"` / `Semantics(label: "ContractorHub AI")`
- TypingIndicator: `aria-label="ContractorHub AI is typing"` (web) / `Semantics(label: "AI is responding")` (mobile)
- OfflineBanner: `role="alert"` (web) / `Semantics(liveRegion: true)` (mobile)
- Image thumbnails: require `alt` text set to "Attached image" (web) / accessible label (mobile)
- All CTAs: minimum 48px touch target on mobile
- Color contrast: all text-on-bubble combinations must meet WCAG AA (4.5:1 for body text)
- Send IconButton (mobile): `Semantics(label: "Send message", button: true)` wrapping the send `IconButton`
- Attach IconButton (mobile): `Semantics(label: "Attach image", button: true)` wrapping the attach `IconButton`
