<!-- Backend API contract for AI endpoints -->

POST /api/v1/ai/intake/start
  Query: project_id?: UUID
  Response 201: { id, company_id, project_id, scope_id, user_id, conv_type, status, version, created_at, updated_at }

POST /api/v1/ai/intake/message
  Body: { conversation_id: UUID, message: string, image_ref_id?: UUID }
  Response: SSE stream with event types:
    - "token": { delta: string }
    - "tool_call": { tool: string, input: object, id: string }
    - "done": { stop_reason: string }
    - "error": { message: string }

POST /api/v1/ai/intake/complete
  Body: { conversation_id: UUID, trade_scopes: [{trade_name, trade_color, sort_order}], project_name: string, project_description?: string }
  Response: { project_id: UUID, trade_scope_ids: UUID[] }

POST /api/v1/ai/interview/start
  Query: scope_id: UUID
  Response 201: ConversationResponse

POST /api/v1/ai/interview/message
  Body: { conversation_id: UUID, message: string }
  Response: SSE stream (same event types as intake)

POST /api/v1/ai/interview/complete
  Body: { conversation_id: UUID, tasks: [{title, description?, priority?, estimated_hours?, sort_order, materials_needed?}] }
  Response: { task_ids: UUID[] }

GET /api/v1/ai/conversations/{conversation_id}
  Response: { ...conversation, messages: AIMessageResponse[] }

1. Create `web/src/app/api/ai-chat/route.ts` — SSE streaming proxy:
   - `export const dynamic = "force-dynamic";`
   - `export const maxDuration = 60;`
   - Export POST handler that:
     a. Reads access_token from cookies (same pattern as proxy/route.ts)
     b. Returns 401 if missing
     c. Reads request body as text
     d. Reads `path` from request URL search params (e.g., `/api/v1/ai/intake/message`)
     e. Validates path starts with `/api/v1/ai/` (SSRF prevention)
     f. Fetches upstream: `fetch(FASTAPI_URL + path, {method: "POST", headers: {Authorization, Content-Type}, body})`
     g. Returns `new Response(upstreamRes.body, {status: upstreamRes.status, headers: {"Content-Type": "text/event-stream; charset=utf-8", "Cache-Control": "no-cache, no-transform", "Connection": "keep-alive"}})`
     h. CRITICAL: Do NOT call `upstreamRes.text()` — pipe ReadableStream directly
   - Also export GET handler for non-streaming endpoints (conversation fetch): standard proxy pattern with buffered response

2. Create `web/src/features/ai/hooks/useIntakeChat.ts`:
   - Manages state: `messages: ChatMessage[]`, `isStreaming: boolean`, `currentStreamText: string`, `tradeScopes: TradeScope[]`, `error: string | null`
   - `ChatMessage` type: `{id: string, role: 'user' | 'assistant', content: string, toolCalls?: ToolCall[], timestamp: Date}`
   - `ToolCall` type: `{tool: string, input: Record<string, unknown>, id: string}`
   - `startConversation(projectId?: string)`: POST to `/api/ai-chat?path=/api/v1/ai/intake/start` with projectId query
   - `sendMessage(message: string)`:
     a. Add user message to messages array
     b. Set isStreaming=true
     c. POST to `/api/ai-chat?path=/api/v1/ai/intake/message` with `{conversation_id, message}`
     d. Read response body as ReadableStream via `res.body.pipeThrough(new TextDecoderStream()).getReader()`
     e. Parse SSE lines: for each line starting with `data: `, parse JSON
     f. On event "token": append delta to currentStreamText, update last assistant message
     g. On event "tool_call": if tool is "create_trade_scope", add to tradeScopes array; if "ask_clarifying_question", append question text to assistant message
     h. On event "done": finalize assistant message, set isStreaming=false
     i. On event "error": set error message, set isStreaming=false
   - `completeIntake(projectName, projectDescription, editedTradeScopes)`: POST to complete endpoint, return project_id
   - `removeTradeScope(index)`, `updateTradeScope(index, updates)`, `reorderTradeScopes(newOrder)` — local state mutations on tradeScopes
