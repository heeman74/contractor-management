3. `BudgetService.apply_quote_delta(quote: Quote) -> None`:
```python
MINIMUM_BUDGET_TOTAL = Decimal("0.01")   # budgets_total_positive_check floor

async def apply_quote_delta(self, quote: Quote) -> None:
    """Adjust the budget linked to an approved quote by the revision delta (BUDG-04).

    D-06 linkage: trade-scope quote -> that scope's budget; job quote ->
    jobs.project_id's budget (no project, no-op); project-level quote ->
    quote.project_id's budget. D-08: no budget at the anchor, no-op. D-09: the
    first approval in a chain establishes the baseline and applies nothing.
    """
```
   Steps, each a named private helper so the method stays short:
   - `_budget_for_quote(quote)` → the linked `Budget | None` per D-06; `None` → return.
   - `previous = await QuoteRepository(self.db).previous_approved_in_chain(quote)`;
     `None` → return (baseline established, D-09).
   - `delta = self._pre_tax_total_of(quote) - self._pre_tax_total_of(previous)`
     where `_pre_tax_total_of` builds `DocumentAmounts(subtotal=sum(item.quantity * item.unit_price
     for item in quote.line_items), discount_type=..., discount_value=..., tax_rate=...)`
     and calls `quoted_revenue(...)`. `delta == 0` → return.
   - `new_total = max(budget.total + delta, MINIMUM_BUDGET_TOTAL)`;
     `await self.repository.set_total(budget, new_total)` — which re-arms on an
     increase (D-03) and leaves fired state alone on a decrease.
   - `await self.evaluate_budget(budget)` in the same transaction, so a
     below-spend result fires its overrun alert immediately (D-07 honesty).
