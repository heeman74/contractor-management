Layout: `space-y-2` list; each row `flex items-center justify-between text-sm`.
Fixed row order: **Labor, Materials, Subcontractor, Other**, then custom categories
alphabetically. Category rows render only when the API returned them; the Labor row
ALWAYS renders on job/project variants (even at $0.00 with unrated hours). A
`Separator` precedes the Total row, whose label and amount are both
`font-semibold text-gray-900`.

Labor row (job/project): left = `Labor` label + `lucide` `Info` icon
(`h-3.5 w-3.5 text-gray-400 hover:text-gray-600`) as the `PopoverTrigger` button with
`aria-label="About labor cost"`; right = the unrated badge
(`text-xs rounded-full px-2 py-0.5 bg-brand/15 text-amber-900`) immediately left of the
amount when `unratedSeconds > 0`, then the amount in `font-semibold`.

Trade-scope variant: labor row shows `Tracked at job level` in `text-xs text-gray-500`,
no popover, no badge, no `$0`. Total row = category totals only.

States: loading -> amounts render `—`; fetch error -> the inline error line replaces the
summary (the entry list below still renders); when `grand_total` is `$0.00` AND
`unrated_seconds === 0` AND `categories` is empty -> render nothing (the existing
