```python
class QuoteSuggestionService(TenantScopedService[Quote]):
    """Grounded line-item suggestions for one draft quote (FINAI-03, FINAI-04).

    candidate -> payload -> validate -> persist, transferred from
    ProfitabilityService. Two differences: validation runs over BOTH the
    structured fields and the basis text, and any failure in either drops the
    whole set rather than part of it — a half-validated quote is not a quote.
    """

    async def suggest(self, quote_id: uuid.UUID) -> SuggestionOutcome
```
Order of operations, each step its own short method:
1. `_get_quote_or_404`, then `_require_quote_status(quote, {"draft"}, "suggest")`
   — reuse the shipped 409 idiom, do not invent a second one.
2. Resolve the trade key through the Trap 3 ladder. An unresolvable key returns
   `trade_unresolved` immediately.
3. Fetch comparables, reduce with `summarize_comparables`.
4. **Cold-start gate, before anything else touches a client or builds a payload**
   (D-09, Pitfall 5): `if summary.comparable_count < MIN_COMPARABLES_FOR_SUGGESTION`
   return `insufficient_history` carrying `trade_name`, `comparable_count` and
   `required_count`. The Claude client must not be constructed on this path.
5. `build_suggestion_payload(summary)`.
6. Draft loop, copying `_draft_for`'s shape with `GROUNDING_RETRY_LIMIT = 1`:
   call `call_claude_json_strict`, then validate EVERY line —
   `ungrounded_line_fields(line, payload.allowed_lines)` for the structured
   fields and `validate_typed_grounding(basis, payload.allowed_figures)` for the
   prose — plus the length bound. Any offender anywhere retries once naming the
   offenders; a second failure drops the whole set and returns `ungrounded`.
   Note in the docstring that a raised transport error consumes no retry: the
   exception escapes before the loop can iterate (36-09).
7. Compose each basis as `SERVER_BASIS_PREFIX_TEMPLATE % (...)` plus the model's
   interpretive clause, and set `confidence_band` from `summary.confidence_band`.
   Read no band, no score and no count from the reply — a self-reported
   confidence is exactly the unverifiable claim this milestone exists to prevent.
8. Persist: delete ONLY rows where `ai_origin` is true AND
   `review_state == REVIEW_STATE_UNREVIEWED`, then insert the new suggestions
   with `ai_origin=True`, `review_state=REVIEW_STATE_UNREVIEWED`,
   `suggested_at=datetime.now(UTC)`, and `sort_order` continuing after the kept
   rows. Never route this through the quote-update path — that method reconciles a
   client-supplied list and is not what regeneration is (Pitfall 2). The
   acceptance greps below forbid the update-path and reply-band identifiers
   anywhere in this file, comments included, so state those two rules in prose
   without naming the symbols.
   Write `quote.ai_suggestion_payload = jsonb_payload(payload.payload)` so a
   shipped suggestion stays re-verifiable against the figures it was validated
   against.
