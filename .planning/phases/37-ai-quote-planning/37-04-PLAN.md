class QuoteVarianceService(TenantScopedService[Quote]):

    contributing_anchor_cost for the cost leg — because a second definition of
    either is the drift 34-02/35-05/35-06 recorded rules against. Quote line

Shape of `quote_variance`, kept to short single-purpose helpers:

1. Load the quote with line items (`repository.get_with_line_items`), 404 if absent.
2. Build `DocumentAmounts(subtotal=sum(quantity * unit_price), discount_type,
   discount_value, tax_rate)` and take the quoted leg from
   `margin_math.quoted_revenue` — never a hand-rolled discount.
3. Branch on the anchor:
   - `job_id` set: actual = `FinanceService.job_cost_breakdown(job_id).grand_total`;
     `labor_included` = that breakdown's labor block is present and non-zero;
     `scope_anchored` = False.
   - `trade_scope_id` set: actual = `FinanceService.trade_scope_spend(scope_id)`;
     `labor_included` = False; `scope_anchored` = True. State in the docstring
     that a scope anchor structurally contains zero labor (Trap 6), which is why
     the caption exists rather than why the number is wrong.
   - both NULL (project-level, D-14): group line items by normalised `field`
     (`strip().casefold()`, empty and NULL dropped), allocate the quoted leg with
     `prorated_pre_tax_totals`, and match each group to the job in
     `quote.project_id` whose normalised `trade_type` equals the group key —
     which is exactly what `_convert_project_quote` created at approval. Fetch
     those jobs in ONE query keyed on `project_id`, and their costs from ONE
     `anchor_cost_context(quote.project_id)`. Phase 33's D-14 last-resort rule is
     deliberately NOT reused; say so in the docstring, because it governs revenue
     resolution and a blended whole-project number would defeat the per-trade
     loop this phase closes.
4. "Comparable" gate (D-02): an anchor contributes an `actual` only when it has
   at least one non-deleted invoice. Determine that with ONE
   `invoice_amounts_query()` filtered to the anchor ids in play. Without an
   invoice the figures are `None`, never `0` — a missing comparison is not a
   variance of nothing.
5. Compute the figures through `quote_history_math.variance_for`.

Return a frozen dataclass; convert to the response schema in `schemas.py`
(`QuoteVarianceResponse`, `QuoteVarianceTradeResponse`, both inheriting the
project's response-schema conventions, all money and percent fields serialized as
`str | None`).
