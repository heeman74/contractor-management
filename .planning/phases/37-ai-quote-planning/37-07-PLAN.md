```python
class QuoteComparableRepository(TenantScopedRepository[Quote]):
    """Same-trade completed work, in a fixed number of round trips.

    Every predicate here is composed from the shipped finance query builders
    rather than restated: a second definition of the invoice or approved-quote
    traversal would drift from the margin rollup, which is exactly what 35-05's
    equivalence test exists to catch.
    """

    async def comparables_for_trade(self, trade_key: str) -> ComparableRows
```
`ComparableRows` is a frozen dataclass of plain rows — no ORM entities, no Row
objects escaping the repository.

Round trips, all column-only, all constant in comparable count:
1. Job anchors: `select(Job.id, Job.trade_type).where(Job.deleted_at.is_(None), func.lower(func.trim(Job.trade_type)) == trade_key)`
2. Scope anchors: the same shape over `TradeScope.id, TradeScope.trade_name`
3. Cost sums per anchor:
   `select(CostEntry.job_id, CostEntry.trade_scope_id, func.sum(CostEntry.amount)).where(CostEntry.deleted_at.is_(None), or_(job_id.in_(...), trade_scope_id.in_(...))).group_by(CostEntry.job_id, CostEntry.trade_scope_id)`
4. Costable sessions for the job anchors: `costable_sessions_query().where(TimeEntry.job_id.in_(job_ids))` → `to_work_sessions`
5. Rates: `LaborRateRepository(self.db).list_rates_for_users(contractor_ids)`
6. Invoice amounts: `invoice_amounts_query()` with an anchor `IN` filter
7. Approved quote amounts: `approved_quote_amounts_query()` with an anchor `IN` filter (keep its shipped newest-first ordering)
8. Line items of those approved quotes:
   `select(QuoteLineItem.quote_id, QuoteLineItem.item_type, QuoteLineItem.description, QuoteLineItem.quantity, QuoteLineItem.unit, QuoteLineItem.unit_price).where(QuoteLineItem.quote_id.in_(quote_ids), QuoteLineItem.deleted_at.is_(None))`

Return `[]`-shaped empties without a round trip when an id list is empty (the
`list_rates_for_users` precedent) — an `IN ()` is a wasted trip, not a filter.

Read every amounts row BY LABEL through `to_anchored_amounts`; never index past
the shared six columns positionally.

Eligibility (applied in Task 2's reduction, not in SQL, so the predicate stays
readable and testable): an anchor is a comparable when its normalised trade key
matches, it has at least one invoice, and its actual cost is greater than zero —
use `margin_math.missing_cost_data` as the zero-cost predicate rather than
re-deriving it. Without that third condition a pre-v4.0 anchor with an invoice
and no cost entries becomes a 100%-margin comparable and poisons the dataset;
PITFALLS #9 names AI quote planning as the feature most directly poisoned by it.

```python
@dataclass(frozen=True)
class AllowedLineValues:
    """The exact values a suggested line may carry in its STRUCTURED fields.

    Exact Decimal membership, never the whole-dollar loosening that money prose
    gets: a structured field is a number the model copied out of the payload, not
    a number it formatted for a sentence.
    """
    unit_prices: frozenset[Decimal]
    quantities: frozenset[Decimal]

@dataclass(frozen=True)
class SuggestionPayload:
    payload: dict[str, object]
    allowed_figures: AllowedFigures
    allowed_lines: AllowedLineValues

def build_suggestion_payload(summary: ComparableSummary) -> SuggestionPayload
def ungrounded_line_fields(line: Mapping[str, object], allowed: AllowedLineValues) -> tuple[str, ...]
def jsonb_payload(payload: Mapping[str, object]) -> dict   # default=str, the 36 audit-trail shape
```

Payload composition — this is the entire D-03 guarantee, so be exact:
- **Money set (citable as `$`):** `median_quoted_unit_price` on every rate row,
  `median_actual_total_per_comparable`, `median_actual_labor_cost`. Emitted as
  `Decimal`.
- **Percent set (citable as `%`):** `quoted_vs_actual_variance_percent`. Emitted
  as `Decimal`.
- **In NEITHER set, and emitted as STRINGS so `collect_allowed_values` skips
  them:** `comparable_count`, `confidence_band`, every `typical_quantity`, and
  the trade name. `collect_allowed_values` skipping strings is the documented
  escape hatch 36-05 relied on ("a project named 2026 can never make `$2,026`
  citable"); this is the same trick, used deliberately.
- Carry `labor_basis: "unburdened"` as a string beside any labor figure, and have
  the prompt repeat it (plan 37-09).

`ungrounded_line_fields` checks `unit_price` and `quantity` only, coercing
through a small `_as_decimal` that returns `None` for anything non-numeric so a
malformed reply is flagged rather than crashing.
