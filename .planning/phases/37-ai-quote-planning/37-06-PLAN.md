<objective>
Make the send gate visible and honest on `/quotes/[id]`: the blocked-send alert,
the disabled-and-explained Send button, the read-only AI line anatomy, and the
409 path for a stale client.

Purpose: D-07 requires the UI to explain WHY, not merely disable. The disable
stops a click that is guaranteed to fail; the alert names the count, the remedy
and the fact that the rule is server-side; and the 409 path stays live and
honestly worded, which is the case that proves the disable was never the
guarantee.

Output: the alert branch, the button linkage, the read-only chip/basis rows, the
409 wiring, and the jest file covering states 33-36.
</objective>
