  <action>
    Create QuoteRepository(TenantScopedRepository) with:
    - get_with_line_items(db, quote_id) — selectinload(Quote.line_items), joinedload(Quote.job)
    - get_for_job(db, job_id) — latest non-deleted quote for job
    - get_active_quotes(db) — all non-deleted, non-revised quotes

    Create QuoteService(TenantScopedService) with:
    - create_quote(db, job_id, data: QuoteCreate, user_id) — creates Quote with status=draft, creates QuoteLineItem rows from data.line_items, appends "quote_created" to job.status_history JSONB. Validate job is in Quote status.
    - update_quote(db, quote_id, data: QuoteUpdate) — only if status=draft. Full line item replacement (delete existing, create new from data.line_items).
    - send_quote(db, quote_id) — sets status=sent, sent_at=now(). Appends "quote_sent" to job.status_history. Triggers FCM notification to job's client (reuse NotificationService). Only if status=draft.
    - record_view(db, quote_id, viewer_id) — sets viewed_at only if NULL (first view). Appends "quote_viewed" to job.status_history.
    - approve_quote(db, quote_id, client_user_id) — validates: status must be sent or viewed, quote not expired (expiry_date check). Sets status=approved, approved_at=now(). Appends "quote_approved" to job.status_history. If job has contractor and dates assigned, transitions job Quote->Scheduled. Triggers FCM notification to admin.
    - decline_quote(db, quote_id, client_user_id, reason, detail) — validates status sent/viewed. Sets status=declined, declined_at, decline_reason, decline_detail. Appends "quote_declined" to job.status_history. FCM to admin.
    - revise_quote(db, quote_id, data: QuoteUpdate) — only if status in (sent, viewed, declined, expired). Sets current quote status=revised. Creates NEW Quote row with revision_number+1, status=draft, copies line items. Returns new quote.
    - extend_expiry(db, quote_id, new_expiry_date) — updates expiry_date, if status=expired resets to sent.
    - save_as_template(db, quote_id, template_name) — creates QuoteTemplate from quote's line items (serialized as JSON).
    - load_template(db, template_id) — returns template data for pre-filling quote builder.
    - list_templates(db) — all templates for tenant.

    Helper: _append_status_history_event(db, job_id, event_type, user_id) — loads job, appends {type, user_id, timestamp} to status_history JSONB list, flushes.

    Create InvoiceRepository(TenantScopedRepository) with:
    - get_with_line_items(db, invoice_id) — selectinload
    - get_for_job(db, job_id) — invoice for a job

    Create InvoiceService(TenantScopedService) with:
    - generate_from_quote(db, job_id, user_id) — validates job is in Complete status with an approved quote. Generates sequential invoice number via SELECT FOR UPDATE on company row (see Research Pattern 2). Creates Invoice copying quote's line items, tax_rate, discount. Sets issued_at=now(). Transitions job to Invoiced. Appends "invoice_generated" to job.status_history. FCM to client.
    - generate_manual(db, job_id, data: InvoiceCreate, user_id) — for jobs without quotes. Same numbering, same transition.
    - update_invoice(db, invoice_id, data: InvoiceUpdate) — only if not finalized. Allows editing line items, due date.
    - finalize_invoice(db, invoice_id) — sets finalized_at, prevents further edits.
    - update_payment_status(db, invoice_id, status) — update status to unpaid/partially_paid/paid. Validate transition is reasonable (no paid->unpaid).

    Create ReportingService with:
    - get_dashboard(db, company_id, start_date, end_date) -> DashboardResponse:
      1. Jobs by status: SELECT status, COUNT(*) FROM jobs WHERE company_id=X AND created_at BETWEEN dates GROUP BY status
      2. Revenue by month: SELECT DATE_TRUNC('month', issued_at), SUM(CASE WHEN status='paid' ...), SUM(CASE WHEN status!='paid' ...) FROM invoices GROUP BY month
      3. Contractor utilization: For each contractor, SUM booked hours from bookings in date range vs available hours (working_hours config * workdays). Return utilization_percent.
      4. Quote conversion: COUNT quotes by status (approved, declined, sent/viewed as pending). conversion_rate = approved / (approved + declined).
    - get_contractor_stats(db, contractor_id, start_date, end_date) — limited view: own utilization, own job counts by status. No revenue data.

    All services inherit TenantScopedService. Use db.flush() when needing IDs before commit (CLAUDE.md rule: do NOT call db.commit()). Use selectinload for one-to-many, joinedload for many-to-one.
