  <action>
    Create QuoteDao (@DriftAccessor) following NoteDao pattern:
    - watchQuotesForJob(jobId) -> Stream<List<QuoteEntity>> — joins with quote_line_items, filters deleted_at IS NULL, orders by revisionNumber DESC. Returns QuoteEntity with populated lineItems.
    - watchQuote(quoteId) -> Stream<QuoteEntity?> — single quote with line items.
    - createQuote(QuoteEntity) — inserts Quote row + all QuoteLineItem rows. Enqueues to sync queue with payload containing quote + line items (parent-child sync pattern from Research).
    - updateQuote(QuoteEntity) — deletes existing line items, inserts new ones. Enqueues update to sync queue.
    - deleteQuote(quoteId) — soft delete (set deletedAt). Enqueue delete.
    - getAllQuotes() -> Stream<List<QuoteEntity>> — all non-deleted quotes for sync/listing.

    Template operations (local only, no sync queue):
    - watchTemplates() -> Stream<List of template rows>
    - createTemplate(name, lineItemsJson, taxRate)
    - deleteTemplate(id)

    Create InvoiceDao (@DriftAccessor) following same pattern:
    - watchInvoicesForJob(jobId) -> Stream<List<InvoiceEntity>>
    - watchInvoice(invoiceId) -> Stream<InvoiceEntity?>
    - createInvoice(InvoiceEntity) — inserts Invoice + InvoiceLineItem rows. Sync queue.
    - updateInvoice(InvoiceEntity) — sync queue.
    - updatePaymentStatus(invoiceId, status) — sync queue.
    - getAllInvoices() -> Stream<List<InvoiceEntity>>

    Create QuoteSyncHandler(SyncHandler):
    - entityType = 'quotes'
    - pull(data) — upserts quote row from server data. Also processes nested line_items array (delete existing for this quote, insert new). Uses on_conflict_do_nothing pattern for idempotent sync.
    - push(item) — sends quote + line items as single payload to POST/PATCH endpoint.

    Create InvoiceSyncHandler(SyncHandler):
    - entityType = 'invoices'
    - Same pull/push pattern as QuoteSyncHandler, handling nested line items.

    Register both handlers in SyncRegistry (sync_registry.dart):
    - Add QuoteSyncHandler and InvoiceSyncHandler to the handler map.
    - Also register line item handlers if sync sends them separately (decision: parent-child, so handled within quote/invoice handlers).

    DAO stream queries must join line items efficiently — use a transaction with two queries (parent + children) rather than a complex JOIN that duplicates parent rows per line item.
  </action>
