`/api/v1/projects/{id}/cost-entries` API and a passing `test_phase_31_e2e.py` cost-entry
suite. The `cost_receipts` table exists but its endpoints/serving land in Plan 31-02.

    Create backend/app/features/finance/repository.py: `class FinanceRepository(TenantScopedRepository[CostEntry])`.
    Methods (each custom query MUST add `.where(CostEntry.deleted_at.is_(None))` — inherited
    list_all() does NOT filter soft-deleted):
    - `list_for_job(self, job_id) -> list[CostEntry]`: select(CostEntry).where(CostEntry.job_id==job_id,
      CostEntry.deleted_at.is_(None)).options(joinedload(CostEntry.category)).order_by(CostEntry.incurred_date.desc()); return scalars().unique().all().
    - `list_for_trade_scope(self, trade_scope_id) -> list[CostEntry]`: same shape, filter trade_scope_id.
    - `rollup_for_project(self, project_id) -> list[CostEntry]`: ONE query joining LEFT OUTER to
      TradeScope (on CostEntry.trade_scope_id==TradeScope.id) and Job (on CostEntry.job_id==Job.id),
      WHERE (TradeScope.project_id==project_id) | (Job.project_id==project_id), and
      CostEntry.deleted_at.is_(None); joinedload(CostEntry.category); return the itemized list.
      The service computes the Decimal total via sum over the returned entries (single DB round trip).
    - `get_entry_or_404(self, entry_id) -> CostEntry`: fetch by id with category joinedload, filter
      deleted_at.is_(None); raise HTTPException(404) if None.
    - `soft_delete(self, entry_id)`: load via get_entry_or_404, set deleted_at=datetime.now(UTC), flush.
    - `list_categories(self) -> list[CostCategory]`: select(CostCategory).order_by(CostCategory.name).
