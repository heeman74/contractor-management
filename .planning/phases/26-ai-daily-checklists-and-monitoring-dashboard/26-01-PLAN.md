2. Create `backend/app/features/checklists/service.py`:
   - `ChecklistService(TenantScopedService[DailyChecklist])` with:
     - `generate_daily_checklists(company_id, target_date)`:
       a. Query all active projects for the company with `selectinload(Project.trade_scopes).selectinload(TradeScope.tasks)`.
       b. For each trade scope with an assigned contractor, filter tasks where: status NOT IN ('complete', 'cancelled'), deleted_at IS NULL, AND (start_date <= target_date OR start_date IS NULL), AND status != 'blocked'.
       c. If no tasks for a contractor on this date, skip.
       d. Build user_content string with project name, trade name, task titles, due dates, dependency statuses, and any GC notes.
       e. Call `AsyncAnthropic().messages.create()` (non-streaming, model="claude-sonnet-4-6", max_tokens=2048, system=CHECKLIST_SYSTEM_PROMPT) with the user_content.
       f. Parse JSON from response.content[0].text (strip markdown fences if present).
       g. Build summary_text: "You have {N} tasks today: {top 3 titles}..."
       h. Upsert into daily_checklists via repository (ON CONFLICT DO UPDATE for idempotency).
       i. Fire FCM push via `asyncio.create_task(notification_svc.send_checklist_notification(...))`. Push body = summary_text.
       j. Add `asyncio.sleep(0.5)` between Claude API calls per contractor to avoid rate limits.
       k. Wrap each contractor's generation in try/except — log error, continue to next.
     - `get_today_checklist(contractor_id, target_date)` — returns checklist for contractor on date.

5. Create `backend/app/features/dashboard/service.py`:
   - `DashboardService(TenantScopedService[DashboardAlert])` with:
     - `get_project_status_cards(company_id)`:
       a. Query active projects with `selectinload(Project.trade_scopes).selectinload(TradeScope.tasks)` and `deleted_at IS NULL`.
       b. For each project, compute: overall_completion_pct, per-trade TradeStatusBadge (blocked if any task status='blocked', at_risk if any task past due_date and not complete, on_track otherwise), active_alert_count from dashboard_alerts.
       c. Return list of ProjectStatusCard.
     - `get_trade_tasks(trade_scope_id)`:
       a. Query tasks for scope with selectinload for dependencies.
       b. Return list of TradeTaskDetail with status, assignee, dates, dependency_status.
     - `get_trade_timeline(project_id)`:
       a. Query trade scopes with tasks for project.
       b. For each scope: start = min(task.start_date), end = max(task.due_date), progress = completed/total * 100.
       c. Query task_dependencies for cross-scope links.
       d. Return timeline data (scopes with dates, progress, dependency links).
     - `detect_schedule_slips(company_id, target_date)`:
       a. Query all active projects with trade scopes and tasks (same selectinload pattern).
       b. For each task: if status NOT IN ('complete','cancelled') AND due_date < target_date, compute days_behind.
       c. Group by trade scope. If max days_behind for a scope > 1, generate alert.
       d. Use DependencyService pattern to find affected downstream scopes.
       e. Call Claude API (non-streaming) with ALERT_SYSTEM_PROMPT + context of which trade is behind and downstream trades.
       f. Store alert in dashboard_alerts via repository.
       g. asyncio.sleep(0.5) between Claude calls.
     - `accept_rescheduling(alert_id)`:
       a. Load alert, extract rescheduling_payload.
       b. For each task in payload, update task.start_date and task.due_date.
       c. Mark alert rescheduling_accepted=True.
     - `dismiss_alert(alert_id)` — mark rescheduling_accepted=False via repository.
     - `mark_alert_read(alert_id)` — mark is_read=True via repository.
