- Offline client profile edits return HTTP 404, are `markParked`, and never reach the backend
- **Pull-side CRM sync works correctly.** Direct API calls from CRM management screens work correctly.
- **Not a requirement blocker:** CLNT-01 is satisfied — CRM profiles, job history, and admin management all functional. Only offline-first mutations of client profiles through the sync queue are affected.
- **Fix:** Update `client_profile_sync_handler.dart` push URLs to match backend routes
